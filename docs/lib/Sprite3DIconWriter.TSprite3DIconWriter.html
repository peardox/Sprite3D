Sprite3DIconWriter

Declaration

type TSprite3DIconWriter = class abstract(TObject)

Description

Base class for an icon file format.

A descendant overrides the class functions that describe its format and SaveToStream, which writes it. Create one writer per save; writers hold no state between saves unless a descendant adds options. For the main thread only, as FMX bitmaps are.

Public procedure SaveToFile(const AImages: array of TBitmap; const AFileName: String);

Writes the images to a file in this format.

Creates the file's folder if needed and replaces any existing file. Blocks while writing. If writing fails, the part-written file is deleted.

Parameters
AImages
The images, as for SaveToStream.
AFileName
The full path to write; it is used as given, so pass it through FixFileName first to be sure of the extension.
Exceptions raised
Exception
If the images are unsuitable, as for SaveToStream, or the file cannot be written.
