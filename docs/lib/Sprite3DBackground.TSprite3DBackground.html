Unit

Sprite3DBackground

Declaration

type TSprite3DBackground = class(TControl)

Description

Shows a background behind a viewport, as a 2D control.

Create it and call AttachTo with the viewport. It becomes the viewport's sibling, directly behind it, with the same alignment and margins, so it covers the same area; if the viewport is not aligned, it copies the viewport's bounds once, and does not follow later moves. It makes the viewport's Color fully transparent while it has something to show. It takes no mouse or touch input and is never stored. Set Spec to change what it shows. For the main thread only.

Public procedure AttachTo(const AViewport: TGorillaViewport);

Puts the background behind AViewport.

Makes it a child of the viewport's parent, or of its owner if it has no parent yet, placed just before the viewport so it is painted first. It takes the viewport's Align and Margins, or its bounds if it is not aligned, so set the viewport's alignment first. The viewport's Color at this moment is kept as the colour shown for None; if it is already fully transparent, black is kept instead. Then the viewport's Color is set for the present spec. Call it once.

Parameters
