Unit

Sprite3DBackground

Declaration

type TSprite3DBackground = class(TDummy)

Description

Draws a background behind everything a TSprite3DCamera sees.

Create it and call AttachTo with the camera; it then hangs from the camera's RollPivot and is freed with the camera's rig. Each frame it fits its planes to the view at a depth just inside the far plane, so the scene is always in front of it. Set Spec to change what it shows. While the camera is orthographic the background is kept out of view for now, as it draws black over the scene there. For the main thread only.

Constants

Public MaxCheckerSquares = 150;

The most checker squares of each grey drawn in the view.

A checker that would need more has its squares enlarged by a whole multiple until it fits. Each square is a pair of planes, all made by AttachTo.

Public procedure AttachTo(const ACamera: TSprite3DCamera);

Puts the background behind everything ACamera sees.

Makes it a child of ACamera's RollPivot, beside the camera, so it moves and turns with the camera and is freed with its rig. The first call also makes all its planes, so call it before the view is first drawn.

Parameters
ACamera
The camera to follow.

What the background shows; setting it redraws it.

Public property Hidden: Boolean read FHidden write SetHidden;

True moves the background out of view, as while a grab is drawn.

Its planes are shrunk to a speck and moved away rather than made invisible, so it takes effect for the next drawing even within a frame. False brings it back.
