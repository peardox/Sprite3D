Description

H.264 encoding with Cisco's OpenH264 library, loaded only when it is present.

OpenH264 is Cisco's open-source H.264 encoder. Cisco publishes ready-built copies of it for each platform, and pays the H.264 patent royalties for copies downloaded from Cisco, which is why it is not shipped with Sprite3D: Sprite3DLibraryUpdate downloads it from the address given for the platform, and this unit loads that copy and no other. Without it, Sprite3DVideo writes MPEG-4 Part 2 instead.

SetPreferredOpenH264 names the copy; OpenH264Available loads it the first time it is asked, if it is version 2.0 or later and has the encoder's entry points, and OpenH264Retry tries again after a download. No other folder, and no copy the system may have, is ever tried.

TSprite3DH264Encoder then turns YUV 4:2:0 pictures into H.264 Annex B access units, ready for an MP4 muxer, with its parameter sets available separately for the MP4's header.

The declarations used to call the library are translated from OpenH264's codec_api.h, codec_app_def.h and codec_def.h, Copyright (c) 2013, Cisco Systems, under the BSD 2-clause licence: redistributions of source must keep that notice and binaries must reproduce it in their documentation.

For the main thread, or any one thread at a time.

function OpenH264Available: Boolean;

Whether OpenH264 is loaded, loading it the first time.

The first call loads the copy SetPreferredOpenH264 named, if it is version 2.0 or later and has the encoder; later calls return the same answer at once. With no copy named, the answer is False. The library stays loaded until the program ends.

Returns

True if TSprite3DH264Encoder can be used.

procedure SetPreferredOpenH264(const APath: String);

Names the copy of OpenH264 to load: the one downloaded for this platform.

Call it before OpenH264Available, or before OpenH264Retry once a copy has been downloaded. An empty string means there is none, and H.264 is not offered.

Parameters
APath
The library's full path.
function OpenH264Retry: Boolean;

Loads the named OpenH264 again unless a copy is already loaded.

As OpenH264Available, but a failed earlier attempt does not stop a new one. A loaded copy stays in use until the program ends.

Returns

True if TSprite3DH264Encoder can be used.

function OpenH264LoadedLibrary: String;

function OpenH264Status: String;

Which OpenH264 was loaded and from where, or why none was.
