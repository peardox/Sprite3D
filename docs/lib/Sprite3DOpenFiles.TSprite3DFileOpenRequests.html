Declaration

type TSprite3DFileOpenRequests = class(TObject)

Description

The queue of files the operating system has asked the application to open.

There is one, created when the unit is initialised and reached through FileOpenRequests; do not create or free it. Call TakePending once the application can open files, normally when the main form is shown, then set OnOpenFile for the requests that come later. For the main thread only.

Stops listening for requests; used only by the unit's finalisation.

Public procedure Request(const AFileName: String);

Adds a request, as the platform code does when the system sends one.

If OnOpenFile is set, it is called at once; otherwise the file waits for TakePending. Files that do not exist are ignored. Other sources of files to open, such as files dropped on the window, can use it too.

Parameters
AFileName
The file to open; made a full path.
Public function TakePending: TArray<String>;

Returns and clears the requests so far, and starts listening for more.

The first call also reads the command line, and on Android the intent that started the application. Blocks briefly on Android if a file must first be copied from another app.

Returns

The files asked for so far, oldest first; empty if there are none.

Properties

Public property OnOpenFile: TSprite3DOpenFileEvent read FOnOpenFile write FOnOpenFile;

Called for each request that arrives after TakePending; nil to queue them.

Set it to nil before the object it belongs to is freed. Command-line requests all arrive before TakePending, so on Windows and Linux it is never called.
