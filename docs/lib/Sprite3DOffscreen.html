Description

Renders a Gorilla3D viewport's scene to an off-screen target of any size.

TSprite3DOffscreen is a Gorilla3D render pass. It is attached to a TGorillaViewport and stays switched off until Grab is called. Grab switches it on for one frame: the pass renders the viewport's scene, through the viewport's own camera, into a frame buffer of Width by Height pixels, 256 by 256 unless changed, and the result is read back into an FMX TBitmap and handed to the caller's procedure. The pass then switches itself off again, so it costs nothing between grabs.

The capture is asynchronous. Grab returns at once; the procedure runs on the main thread after the next frame has been drawn, outside the render loop, so it may save files or show dialogs. The viewport must be rendering for this to happen: if it is hidden, for example on another tab, the grab waits until it is shown again, or until Cancel.

The camera's projection is worked out for the target's size. To make the model fill the target, fit the camera to the target's shape in OnBeforeGrab and put it back in OnAfterGrab; the screen never shows the grab's framing.

Read-back uses OpenGL directly, with the GL functions looked up at run time in the platform's library, so it works on every platform Gorilla renders with OpenGL: Windows and Linux with desktop OpenGL, Android with OpenGL ES 3. If a project switches Gorilla to its optional Vulkan backend, grabs fail with an error saying an OpenGL function is not available.

On macOS and iOS Gorilla renders through Metal, so there a grab is instead a screenshot of the viewport as it is shown, from TGorillaViewport.MakeScreenshot, cropped about its centre to the target's shape and scaled to the target's size. OnBeforeGrab and OnAfterGrab are not called, so the framing is the screen's. The on-screen background is a 2D control behind the viewport, so it is not in the screenshot: what is behind the model is the viewport's own Color, fully transparent unless the background is None. For a Solid or Gradient Backdrop, the screenshot is laid over it at the target's size; otherwise the image keeps whatever transparency the screenshot has. Soft edges are not matted as on the other platforms, and TransparentBackground is not used.

Overscan, 1 unless changed, renders each grab at that many times its size each way and scales the result back down to Width by Height with the Resample filter, from Sprite3DResample, which smooths edges far better than the renderer's own anti-aliasing. As much of the factor as the GPU can draw in one go is drawn in one go: a target up to what the GPU can draw and OVERSCAN_TARGET_LIMIT pixels across. Any more is made up with shifted drawings: the grab is drawn J by J times at that size, each time with the view slid by a different fraction of a drawn pixel through OnShiftView, every drawing is scaled down with Resample, and the results are averaged, which samples J times as finely each way. So any factor up to OVERSCAN_MAX can be used whatever the GPU, at the cost of more drawings. Each drawing is matted and scaled down before the next is made, so only one enlarged drawing exists at a time, and what is delivered is always Width by Height. A GPU or driver can report a size it then fails to draw at: if an overscanned drawing comes back smaller than asked for, or wholly transparent, that size is remembered as too large for the rest of the session, OnOverscanReduced is called, and the grab is made again with smaller drawings and more of them. Overscan does not apply on macOS and iOS, where grabs are screenshots.

The matting and the scaling down of each drawing are done on a worker thread, a task from the RTL's thread pool, as they are pure arithmetic on the pixels read back; the render loop and the user interface carry on meanwhile, and the result is picked up on the main thread. Everything else, including every event, stays on the main thread.

function IsOffscreenPass(const APass: TObject): Boolean;

Whether a render pass is a TSprite3DOffscreen grab.

For helpers that draw in the main pass only and skip Gorilla's other passes, such as shadows and reflections, but should also be drawn into grabs, so a grab shows what the view shows. Pass the Gorilla context's CurrentPass.

Parameters
APass
The pass being rendered; nil gives False.
Returns

True if APass is a TSprite3DOffscreen.

DEFAULT_OFFSCREEN_WIDTH = 256;

The width, in pixels, of a new TSprite3DOffscreen's target.

DEFAULT_OFFSCREEN_HEIGHT = 256;

The height, in pixels, of a new TSprite3DOffscreen's target.

OVERSCAN_MAX = 16;

The largest Overscan factor TSprite3DOffscreen accepts.

OVERSCAN_TARGET_LIMIT = 8192;

The most pixels across or down an overscanned target may have, whatever the GPU allows.

Each drawing of a grab is held in memory at the target's size, four bytes a pixel, and a transparent grab needs up to three of them at once and the matte made from them, so this keeps a grab under about 1 GB: 8192 by 8192 pixels is 256 MB each.
