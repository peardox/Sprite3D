Description

Colours the windows' title bars to go with the application's FMX style, where the operating system allows it.

SetTitleBarSpec stores how title bars should look and applies it at once to every form on screen; forms shown later get it as they are shown. TitleBarSpecFromStyle works out a spec from the FMX style in use, taking the colour of its form background. 

Windows 11   caption, caption text and border colours (DWM)
Windows 10   dark or light title bar only (DWM immersive dark mode, build 17763 on)
macOS 10.14  dark or light appearance for the whole application (NSApp.appearance)
Linux        nothing: the window manager draws the title bar
Android, iOS nothing: there is no title bar

Where only dark or light is possible, a caption colour darker than mid grey gives dark. Calls on a system without the feature are ignored. The unit knows nothing of any particular application. Call it on the main thread only.

function StyleBackgroundColour(var AColour: TAlphaColor): Boolean;

The colour of the form background in the FMX style in use.

Reads the backgroundstyle resource that every FMX style draws behind a form; for a gradient, its first colour.

Parameters
AColour
The colour found; unchanged if none is.
Returns

True if the style has a background with a colour.

function TitleBarSpecFromStyle(const AFallback: TAlphaColor; const ABorder: TAlphaColor = TAlphaColors.Null): TSprite3DTitleBarSpec;

A title bar spec to go with the FMX style in use.

The caption takes the style's form background colour, as StyleBackgroundColour reads it, or AFallback if the style has none.

Parameters
AFallback
The caption colour to use if the style's cannot be read.
ABorder
The border colour, often the style's accent; TAlphaColors.Null for the system's.
Returns

The spec.

procedure ApplyTitleBar(const AForm: TCommonCustomForm);

Gives one form's title bar the current spec.

SetTitleBarSpec already does this for every form; call it only for a form whose window has been made again. A form whose window does not exist yet is skipped.
