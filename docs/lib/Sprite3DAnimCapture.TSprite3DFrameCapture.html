Sprite3DAnimCapture

Declaration

type TSprite3DFrameCapture = class(TObject)

Description

One capture run: every frame of a source, grabbed in turn.

Create it, then call Run. Run starts the source, shows frame 0 and asks the off-screen renderer for a grab; the first WarmUpFrames grabs are thrown away, frame 0 being shown again before each, then each grab is copied, the next frame shown and grabbed, and so on. When the last frame is in, or a grab fails, the source is finished, the procedure given to Create is called once with every frame or the error, and the capture frees itself and its source. While it runs, the off-screen renderer is busy for most of the time but not all of it, so the owner should refuse other grabs on its own account.

The capture changes nothing about the framing: the owner frames the camera for the whole run first and restores it in its procedure. Where TSprite3DOffscreen grabs by screenshot (macOS and iOS), each frame is left on screen for SettleTime milliseconds before it is grabbed, so the screenshot shows it.

The off-screen renderer; it must outlive the capture. Its Width and Height are the frame size.

The frames; the capture owns it from here on and frees it.
AOnDone
Called once when the capture ends, unless it is cancelled.
AOnProgress
Called after each frame is grabbed; may be nil.
Public destructor Destroy; override;

Frees the source and any frames not handed over.

Public function Run: Boolean;

Starts the capture; returns at once.

The source has already been started if the owner called its Start itself, for example to measure every frame before framing; Run then does not start it again.

Returns

True if it started; False if the off-screen renderer is busy or has no viewport, in which case the capture has finished its source, called nothing and freed itself.

Public procedure Cancel;

Stops the capture without calling its procedure.

Use it when the owner is going away. The source is finished, and the capture frees itself the next time it would have gone on, or at once if nothing is pending.

Public procedure SourceStarted;

Marks the source as already started by the owner, so Run does not start it again.

Public property SettleTime: Integer read FSettleTime write FSettleTime;

Milliseconds each frame is left on screen before it is grabbed.

0 where grabs render off screen, which draws the frame as it is set; about four display frames where grabs are screenshots.

Public property WarmUpFrames: Integer read FWarmUpFrames write FWarmUpFrames;

How many grabs of the first frame are thrown away before the one that is kept; DEFAULT_WARM_UP_FRAMES by default.

Each waits for a frame to be drawn, so the animation has caught up with its first pose by the time it is kept. Set it before Run; negative values count as 0. They are grabbed without overscan, which is put back for the frames that are kept, so they cost little whatever the overscan.
