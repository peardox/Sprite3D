Unit

Sprite3DAnimCapture

Declaration

type TSprite3DFrameSource = class abstract(TObject)

Description

Something that can be shown one frame at a time for capture.

Call Start once, then ShowFrame for any frame from 0 to FrameCount - 1 in any order, then Finish once. Between Start and Finish the scene is the source's to change.

Hands the scene back; called once, after the last ShowFrame.
