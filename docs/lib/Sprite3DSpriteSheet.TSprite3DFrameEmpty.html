type TSprite3DFrameEmpty = record

Description

The fully transparent border round a frame: how many whole columns or rows at each edge have nothing in them.

The frame's pixels run from (0, 0) at the top left to (width - 1, height - 1) at the bottom right. Left is the number of columns from the left edge before the first one with any pixel that is not fully transparent, Right the number after the last such column, and Top and Bottom the same for rows; so what is drawn lies in columns Left to width - 1 - Right and rows Top to height - 1 - Bottom. A frame with nothing in it at all is empty from every side: Left and Right are its width, Top and Bottom its height.
