Unit Sprite3DFileAssoc

Description
Classes, Interfaces, Objects and Records
Types

Description

Registers an application with the operating system as an Open With choice for file types, and as their default application, and puts things back afterwards.

TSprite3DFileAssociations is given an application name, a programmatic identifier, a description and a list of file types, and works for the current user only; nothing needs administrator rights. Before it makes the application the default for a type it records what the default was, in a backup string the caller keeps, so RestoreDefaults can put the old default back. An old default is only put back if it is still valid: the program it names must still be registered or installed. Otherwise the type is left with no per-user default, and the system's own choice applies again. 

Windows   HKCU\Software\Classes: a ProgID, Applications\<exe>, <ext>\OpenWithProgids,
          and <ext>'s default value for "always"; Capabilities and RegisteredApplications
          so the app is listed in Settings, Default apps. A choice the user made in
          Windows' own dialog (UserChoice) cannot be changed by a program; then
          NeedsUserConfirmation is set and OpenSystemDefaults shows that page.
Linux     a .desktop file in $XDG_DATA_HOME/applications and a shared-mime-info package
          for the types; "always" is the [Default Applications] group of
          $XDG_CONFIG_HOME/mimeapps.list.
macOS     Open With comes from CFBundleDocumentTypes in the bundle's Info.plist and
          cannot be removed at run time; "always" is set through Launch Services.
Android,  not supported: the app declares what it opens when it is built, and the user
iOS       picks the default in the system's chooser.

The unit knows nothing of any particular application. All methods are for the main thread and may block briefly while files, the registry or helper programs are used.

How much of the file associations this platform lets a program change.

asNone: nothing, as on Android and iOS. asDefaultOnly: only which application is the default; Open With is fixed when the app is built, as on macOS. asFull: both, as on Windows and Linux.
