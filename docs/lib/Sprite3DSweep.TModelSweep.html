Declaration

type TModelSweep = class(TDummy)

Description

Draws, as a wireframe beside its model, the swept volume of the animation the model is playing, or of its rest pose.

A TDummy holding Volume, for the rest pose, and a volume per animation, set with SetAnimationVolume. In its own Render, in the main pass only, it picks the volume in use: that of the animation the model is playing, by its Id, if the animation is running and has a volume; otherwise Volume. It draws that volume's swept box in BoxColor and, in SweepColor, the tube's outer wall, its inner wall when it has one, and the axis. Each wall is a ring of Segments lines at each end, joined by four lines along the axis. The lines are worked out again only when the volume in use changes or a setting does.

It belongs beside Model, under the same parent, not inside it, so it never counts in Model's bounding box. Each Render it draws with Model's AbsoluteMatrix, so the lines follow the model wherever it moves, turns or is scaled; it also copies Model's position, rotation, scale and centre of rotation to itself, and sets its own Width, Height and Depth to cover the lines, so anything that culls by an object's size sees them all. Nothing is drawn while Model is nil or hidden, or the volume in use is not Valid.

The object is not stored in .fmx files and ignores the mouse. Use it from the main thread only. ShowModelSweep creates and places one.

Methods

Protected procedure Render; override;

Draws the volume in use with the model's matrix, in the main pass only.

Copies Model's transform to this object if it changed, picks the volume in use and works its lines out if it changed, then, if Model is visible and that volume is Valid, draws the lines with the context matrix set to Model's AbsoluteMatrix, restoring the previous matrix and line state afterwards, even if drawing fails. Does nothing in Gorilla's shadow, reflection and other passes.

Public property Model: TGorillaModel read FModel write SetModel;

The model whose matrix the lines are drawn with and whose playing animation picks the volume; nil draws nothing.

Not owned. If it is freed first the sweep forgets it. Give this object the same parent as the model.

Public property Volume: TSweptVolume read FVolume write SetVolume;

The rest pose's volume, drawn when no animation with a volume is playing.

In Model's own coordinates. Setting it redraws.

Public property ActiveVolume: TSweptVolume read GetActiveVolume;

The volume drawn now: the playing animation's, or Volume.

Worked out from the model's animation at the time of reading, as Render does.

Public property SweepColor: TAlphaColor read FSweepColor write SetSweepColor;

Public property LineWidth: Single read FLineWidth write SetLineWidth;

Line width in screen pixels; 1 by default.

Values above 1 work on desktop OpenGL only; Vulkan, Metal and OpenGL ES always draw 1 pixel. Values below 1 count as 1.

Public property Segments: Integer read FSegments write SetSegments;

Lines in each ring; 64 by default.

More look rounder and cost more to draw. Values below 8 count as 8.
