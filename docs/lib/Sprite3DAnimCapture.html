Description

Grabs every frame of a model's animation, or of a turn of the camera round it, one off-screen grab after another.

A frame source says how many frames there are, how long they last together, and how to show frame N. TSprite3DAnimationFrames shows the frames of one of a Gorilla model's animations, from the first to the last; TSprite3DTurntableFrames turns a TSprite3DCamera once round the model, for a model or a moment with no animation to play.

TSprite3DFrameCapture then shows each frame in turn and grabs it with a TSprite3DOffscreen, starting the next grab from inside the previous one's procedure, as TSprite3DOffscreen.GrabSizes does. The grabs are copied into TSprite3DImage records straight away, so the whole run holds no FMX bitmaps, and the caller gets them all at the end in one procedure, ready for Sprite3DSpriteSheet to lay out and save.

The capture does not frame the model; the owner of the camera sets one framing for the whole run before starting it, so every frame is drawn at the same scale, and puts its own back afterwards.

Everything here is for the main thread. A capture runs over many frames of the main loop; the application stays responsive meanwhile, and should not start other grabs, load another model or change the animation until the capture reports.

TSprite3DFramesProc = reference to procedure(const AFrames: TArray<TSprite3DImage>; const AError: String);

Reports a finished capture: every frame, in order, or an error.

Parameters
AFrames
The frames, first to last, all the grab's size; empty if AError is set. They belong to the procedure.
AError
Empty on success; otherwise why the capture stopped.
TSprite3DCaptureProgress = reference to procedure(const ADone, ATotal: Integer);

Reports progress after each frame is grabbed.

Parameters
ADone
How many frames have been grabbed so far.
ATotal
How many frames there are in all.
