type TSprite3DImage = record

Description

An image as plain RGBA bytes with straight alpha, top row first.

Pixel (X, Y) starts at byte (Y * Width + X) * 4 of Pixels, in the order red, green, blue, alpha. The colour is not premultiplied by alpha, as PNG and GIF expect. A record of value type apart from Pixels, which is a reference-counted dynamic array, so copies share the pixels until one is changed through SetLength or a new array.
