type TSweptVolume = record

Description

The space a bounding box passes through in a full turn about an axis.

A tube round the axis, from InnerRadius to OuterRadius, running from AxialLow to AxialHigh along it; a solid cylinder when InnerRadius is 0. All values are in the model's own coordinates and units. Fill it with CalcSweptVolume. Across the axis the two other axes are taken in X, Y, Z order: X and Z for saY, Y and Z for saX, and X and Y for saZ.

Public Valid: Boolean;

False if the box it was worked out from was empty; nothing else is then set but Axis and Pivot.

The model's axis that the turn is about.

Where the volume starts along the axis: the box's lowest value on it.

Public AxialHigh: Single;

Where the volume ends along the axis: the box's highest value on it.

Public InnerRadius: Single;

The distance from the axis to the nearest point of the box; 0 when the axis passes through the box.

Public OuterRadius: Single;

The distance from the axis to the box's farthest corner.

Public function Length: Single;

How far the volume runs along the axis.

Returns

AxialHigh minus AxialLow; 0 if Valid is False.

Public function Volume: Single;

The swept volume itself: the tube between the two radii.

Returns

Pi times the difference of the squared radii, times Length, in cubic model units; 0 if Valid is False.

Public function BoxVolume: Single;

The volume of the swept box, which holds the whole tube, its hole included.

Returns

Twice OuterRadius, squared, times Length, in cubic model units; 0 if Valid is False.

Public function Box: TBoundingBox;

The swept box: the smallest box, square across the axis, that holds the tube.

It is centred on the axis, 2 times OuterRadius across it each way, and runs from AxialLow to AxialHigh along it. The box cannot show the tube's hole, so it also holds space round the axis that the model never reaches.

Returns

The box in the model's own coordinates; meaningless if Valid is False.

A one-line description for a log, with the radii, length, volumes and swept box size.
