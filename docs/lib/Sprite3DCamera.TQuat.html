type TQuat = record

Description

A quaternion of Doubles, used for the camera's orientation arithmetic.

Hamilton convention, with the right-hand rule on raw coordinates. A * B means apply B first, then A. The rotation helpers expect a unit quaternion; Create does not normalise. TQuat is a plain value type with nothing to free, and may be used on any thread.

Public class function ShortestArc(const AFrom, ATo, AFallbackAxis: TPoint3D): TQuat; static;

Builds the smallest rotation that turns AFrom onto ATo.

Both vectors must be unit length. When they point in opposite directions, with a dot product below -1 + 1E-6, every axis gives an equally short turn, so the result is a 180-degree turn about AFallbackAxis. LookAt passes the camera's own up direction there.

Parameters
AFrom
The starting direction, unit length.
ATo
The target direction, unit length.
AFallbackAxis
The axis used only for opposite vectors; must be perpendicular to AFrom, any non-zero length.
Returns

A unit quaternion that rotates AFrom onto ATo.

Public class function Slerp(const A, B: TQuat; const T: Double): TQuat; static;

Interpolates spherically between two rotations.

Always takes the shorter way round, using -B in place of B where that is nearer to A. When A and B are almost equal it falls back to linear interpolation to avoid dividing by a tiny sine. The result is normalised.

Parameters
A
The rotation at T = 0; unit length.

Returns

The interpolated rotation, as a unit quaternion.
