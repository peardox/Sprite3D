Description

Decompresses bzip2 data in plain Pascal, on every platform.

Cisco publishes its OpenH264 libraries as .bz2 files, and the RTL reads only zlib and gzip, so this unit decodes bzip2 itself. Bzip2Decompress takes a whole compressed file in memory and returns the whole original; concatenated streams, as pbzip2 writes, come back joined. Every block's checksum and each stream's combined checksum are checked, so damaged data raises an error rather than coming back wrong.

Blocks marked "randomised", which no bzip2 since version 0.9.5 of 1999 writes, are refused. Memory use is about five times the largest block, at most 4.5 MB, plus the output.

No state is kept between calls, so it can be used from any thread.

function IsBzip2(const AData: TBytes): Boolean;

Whether data starts as a bzip2 stream does.

Only the four-byte header is checked: BZh and a block size from 1 to 9.

Parameters
AData
The data to look at.
Returns

True if it looks like bzip2.

function Bzip2Decompress(const AData: TBytes): TBytes;

Decompresses a whole bzip2 file held in memory.

Parameters
AData
The compressed data: one or more bzip2 streams, one after another.
Returns

The original data.

Exceptions raised
EBzip2Error
If the data is not bzip2, is damaged, fails a checksum or ends too soon.
EOutOfMemory
If the output cannot be held in memory.
