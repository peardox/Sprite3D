Description

Writes sets of square images as icon files, starting with Windows .ico.

TSprite3DIconWriter is the base for icon formats: each descendant gives its format's name, file extension and the image sizes it normally holds, and writes a set of FMX bitmaps in that format. TSprite3DIcoWriter writes Windows icons. Every format is registered at start-up with RegisterIconWriter, so a program can offer all of them, for example as the file types of a save dialog, through IconWriters and IconDialogFilter; adding a format, such as the macOS .icns format, needs only a new descendant and its registration.

The writers are plain Pascal over FMX bitmaps and streams, so they work the same on every platform. They do not render anything; the images come from the caller, for example from TSprite3DOffscreen.GrabSizes.

procedure RegisterIconWriter(const AWriter: TSprite3DIconWriterClass);

Adds an icon format to those IconWriters lists.

Call it from a writer unit's initialization section. Registering a class twice has no further effect.

Parameters
AWriter
The writer class to add.
function IconWriters: TArray<TSprite3DIconWriterClass>;

Every registered icon format, in the order registered.

Returns

The writer classes; TSprite3DIcoWriter is always first.

function IconDialogFilter: String;

A file dialog Filter offering every registered icon format.

The formats are in the order of IconWriters, so a dialog's FilterIndex, which counts from 1, picks IconWriters[FilterIndex - 1].

Returns

Such as 'Windows icon (*.ico)|*.ico'.
