Declaration

type TSprite3DH264Encoder = class(TObject)

Description

One OpenH264 encoder, for pictures of one size.

Create it with the size and frame rate, feed it every picture in order with Encode, then free it. Every picture is encoded on its own, without frames held back, so each Encode returns that picture's access unit straight away; there are no B-frames, so the decoding order is the display order. Rate control aims at a constant quality, and the encoder never drops a frame.

Public constructor Create(const AWidth, AHeight: Integer; const AFrameRate: Single; const AKeyInterval: Integer);

Sets up an encoder for AWidth x AHeight pictures at AFrameRate.

Parameters
AWidth
The picture width in pixels; even, at least 16.
AHeight
The picture height in pixels; even, at least 16.
AFrameRate
Frames per second, which sets the bit budget; more than 0.
AKeyInterval
Frames between key frames; 0 for only the first.
Exceptions raised
ESprite3DH264Error
If OpenH264 is not available or refuses the settings.

Public function ParameterSets: TBytes;

The sequence and picture parameter sets, as an Annex B byte stream.

This is what an MP4 muxer needs, as the stream's extra data, to write the stream's avcC description before any frame.

Returns

The SPS and PPS NAL units, each after a start code.

Public procedure Encode(const APlanes: array of PByte; const AStrides: array of Integer; out AData: TBytes; out AKey: Boolean);

Encodes one YUV 4:2:0 picture.

Parameters
APlanes
The Y, U and V planes, in that order; U and V are half the width and height.
AStrides
The bytes from one row to the next in each plane.
AData
On return, the picture as an Annex B access unit; empty if the encoder skipped it.
AKey
On return, True if it is a key frame, which a player can start from.

ESprite3DH264Error
