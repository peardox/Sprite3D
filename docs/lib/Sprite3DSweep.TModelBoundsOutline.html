Declaration

type TModelBoundsOutline = class(TControl3D)

Description

Draws a model's bounding box into grabs, as Gorilla's own ShowBoundingBox draws it on screen.

Gorilla draws ShowBoundingBox in the main pass only, so a TSprite3DOffscreen grab would leave it out. This draws the same box, the model's current animated bounds in its own coordinates, in orange by default, but only into a grab, and only while the model's ShowBoundingBox is True; on screen Gorilla's own box is drawn, so nothing is drawn twice. It sits beside the model, not inside it, so it never counts in the model's bounds, and draws with the model's matrix. Made with ShowModelBoundsOutline; owned by the model. Main thread only.
