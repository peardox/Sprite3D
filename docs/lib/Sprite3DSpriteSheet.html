Unit Sprite3DSpriteSheet

Description

Lays out a sequence of frames as a sprite strip, a spritesheet, texture atlas pages or an animated GIF, and writes them to files.

The frames are TSprite3DImage records: plain RGBA pixels with straight (not premultiplied) alpha, top row first, all the same size. ImageFromBitmap makes one from an FMX bitmap, such as a grab from TSprite3DOffscreen, so the frames take no GPU resources and no canvas is involved.

ComposeStrip puts the frames side by side in one row; ComposeSheet puts them in a square grid, left to right and then top to bottom. SavePng writes such an image as a PNG file and SaveAnimatedGif writes the frames as a looping GIF. Both writers are plain Pascal over streams, using only System.ZLib, so they behave the same on every platform and are not limited by the largest bitmap the GPU or FMX canvas accepts: a strip of a hundred frames of 256 pixels is written as easily as a single frame.

GIF keeps 256 colours per frame and on/off transparency, so each frame gets its own palette of up to 255 colours, chosen by median cut, plus one transparent entry; pixels less than half opaque become transparent. Every frame replaces the last (disposal "restore to background"), so transparent sprites animate cleanly.

A texture atlas puts the frames of several animations on shared pages: PlanAtlasPages decides which frames go on each page, filling every page but the last, and how large each page is, and ComposeAtlasPage lays a page out.

MeasureFrameEmpty measures the fully transparent border round a frame, and SaveSheetMetadata writes a strip's, a spritesheet's or an atlas page's metadata as JSON beside it: the image's size and layout, where the model's centre of rotation falls in a frame, the animations it holds, and each frame's transparent border with the smallest of each side over all of them.

Nothing here keeps state, and every routine may be called on any thread, except ImageFromBitmap, which reads an FMX bitmap and so belongs on the main thread. 

frames: TArray<TSprite3DImage>
|-- ComposeStrip  -> TSprite3DImage, Count x 1 frames  -> SavePng
|-- ComposeRows   -> TSprite3DImage, rows of N frames   -> SavePng
|-- ComposeSheet  -> TSprite3DImage, N x N frames      -> SavePng
|-- PlanAtlasPages, then ComposeAtlasPage per page     -> SavePng
|-- SaveAnimatedGif                                    -> .gif
`-- SaveSheetMetadata, from MeasureFrameEmpty          -> .json beside the .png

function ImageFromBitmap(const ABitmap: TBitmap): TSprite3DImage;

Copies an FMX bitmap into a TSprite3DImage, removing premultiplied alpha.

FMX bitmaps hold their colour premultiplied by alpha; the copy divides it back out, so a half-transparent edge keeps its true colour. Works with whichever byte order the platform's bitmaps use. For the main thread only. The bitmap is not changed or freed.

Parameters
ABitmap
The bitmap to copy; not nil and not empty.
Returns

The copy.

Exceptions raised
EArgumentException
If ABitmap is nil or empty.
EInvalidOperation
If the bitmap cannot be mapped for reading.

function ComposeSheet(const AFrames: TArray<TSprite3DImage>; out ACells: Integer): TSprite3DImage;

Puts the frames in a square grid: a spritesheet.

The grid has ACells columns and ACells rows, where ACells is the smallest number whose square holds every frame, so 30 frames make a 6 by 6 grid. Frame I is in column I mod ACells and row I div ACells: the frames run left to right along a row, then carry on at the start of the next row down. Cells after the last frame are left fully transparent.

Parameters
AFrames
The frames, in order; at least one, all the same size.
ACells
On return, the number of columns, which is also the number of rows.
Returns

The spritesheet.

Exceptions raised
EArgumentException
If there are no frames or they differ in size.
EOutOfMemory
If the spritesheet is too large to allocate.

procedure SaveAnimatedGif(const AFrames: TArray<TSprite3DImage>; const AFileName: String; const ADelay: Integer);

Writes the frames as an animated GIF that loops for ever.

Each frame gets its own palette of up to 255 colours, chosen by median cut, and one transparent entry; a pixel less than half opaque is written as transparent. Every frame is shown for ADelay hundredths of a second and then cleared, so transparent frames do not build up on each other. The file replaces any of that name; the folder must exist. Blocks while it writes.

Parameters
AFrames
The frames, in order; at least one, all the same size and each at most 65535 pixels wide and high.
AFileName
The file to write.
ADelay
How long each frame shows, in hundredths of a second. Values below 2 are written as 2, since browsers slow down shorter delays to a tenth of a second.
Exceptions raised
EArgumentException
If there are no frames, they differ in size or they are too large for GIF.
EFCreateError
If the file cannot be created.
EWriteError
If writing fails part way.

function PlanAtlasPages(const AFrameCounts: TArray<Integer>; const AFrameWidth, AFrameHeight, AMaxSize: Integer; const ANonPowerOf2: Boolean): TArray<TSprite3DAtlasPage>;

Plans the pages of a texture atlas: which frames of which animations go on each page, and each page's grid and size.

A texture atlas is the frames of several animations on shared pages. Every frame is a cell of AFrameWidth by AFrameHeight; a page is a grid of such cells no larger than AMaxSize each way, so it holds at most (AMaxSize div AFrameWidth) * (AMaxSize div AFrameHeight) frames. The animations' frames are taken in order, every frame of the first, then every frame of the next, and so on, and fill each page in turn: an animation that does not fit in what is left of a page carries on at the start of the next. So every page but the last is full, a full grid with no cell to spare.

Each page is then made as small as its frames allow; for a full page that is the largest page. With ANonPowerOf2 False, its width and height are the smallest powers of 2 whose grid of whole cells holds them, the smaller area first and then the squarer; its grid is every whole cell that fits. With ANonPowerOf2 True, it is exactly as large as a grid of whole cells that holds them, chosen the same way. The frames fill the grid left to right and then top to bottom. Animations with no frames are skipped.

Parameters
AFrameCounts
The number of frames of each animation, in the order they are to be laid out.
AFrameWidth
The width of every frame, in pixels; at least 1.
AFrameHeight
The height of every frame, in pixels; at least 1.
AMaxSize
The most a page may be each way, in pixels, such as one of 1024 to 16384.
ANonPowerOf2
True lets a page be any size; False keeps both sides powers of 2.
Returns

The pages, in order; empty if there are no frames, or a frame is larger than AMaxSize.

procedure SaveSheetMetadata(const AFileName: String; const AFrames: TArray<TSprite3DImage>; const AInfo: TSprite3DSheetInfo);

Writes the metadata of a sprite strip, spritesheet or texture atlas page as a JSON file.

Each frame is measured with MeasureFrameEmpty. The file is: 

 {
   "meta": {
     "page": 1, "page_count": 1, "total_frames": 8,
     "creator": "...", "creator_url": "...",
     "modeller": "...", "modeller_url": "...",
     "artist": "...", "artist_url": "...",
     "created": "2026-10-01", "modified": "2026-10-23T16:40:00.000+01:00",
     "file": "C:\\Models\\hero.glb"
   },
   "image": {
     "size": { "width": 2048, "height": 256 },
     "sprite_size": { "width": 256, "height": 256 },
     "layout": { "cols": 8, "rows": 1, "frame_count": 8 },
     "origin": { "x": 127, "y": 201 },
     "sprite_empty": { "left": 61, "top": 12, "right": 58, "bottom": 40 },
     "directions": [0],
     "animations": ["walk"],
     "animation_frames": [8],
     "unused": 0
   },
   "frames": [
     {
       "animation": 0,
       "direction": 0,
       "frame": 0,
       "empty": { "left": 64, "top": 12, "right": 60, "bottom": 40 }
     },
     ...
   ]
 }

meta comes first, from AInfo.Meta: the page, from 1, the number of pages, the number of frames the export made over every page in total_frames, the credits, the day the project started, when this export was made, and the model file; empty text is null. size is the whole image's, from AInfo, and sprite_size one frame's, the grab size. origin is the pixel the model's centre of rotation falls on in every frame, in the frame's own pixels, (0, 0) the top left pixel, as whole numbers; null for each if it is not known. sprite_empty holds, for each side, the smallest of the frames' empty borders, so cropping every frame by it loses nothing from any of them. directions lists the directions the image holds, as compass bearings in degrees in the order they are exported; one direction is the single dummy entry 0. animations names the animations the image holds, and animation_frames gives how many frames each has in all, so one that carries on onto another atlas page shows its whole length. unused is the number of the grid's cells after the last frame, which hold nothing. frames has one entry per frame, in the order of the cells, saying which animation and direction it is, as indices into animations and directions, which frame of that animation and direction, counted from 0, and its empty sections in empty. The file is replaced if it exists; the folder must exist.

Parameters
AFileName
The file to write, normally the image's name with the extension .json.
AFrames
The frames, in order, as laid out in the image; at least one, all the same size.
AInfo
The image's size, grid, origin, directions, animations, and which each frame is.
Exceptions raised
EArgumentException
If there are no frames, they differ in size, AInfo's grid cannot hold them, or AInfo.Frames does not match them or names an animation or direction it does not list.
EInOutError
or another file exception if the file cannot be written.
function SafeFileStem(const AName: String): String;

A name made safe to use as a file name on every platform.

Characters that Windows, macOS, Linux, Android or iOS reject or treat specially in file names, such as / \ : * ? " < > | and control characters, become underscores, and leading and trailing spaces and dots are removed. An empty result becomes 'animation'.

Parameters
AName
The name, such as an animation's name.
Returns

The safe name, without a folder or extension.
