Declaration

type TSprite3DIcoWriter = class(TSprite3DIconWriter)

Description

Writes Windows .ico files.

Each image is stored with 32 bits per pixel: 8-bit blue, green, red and alpha. Images smaller than PngMinSize are stored as bitmaps, with the AND mask older readers need, and larger ones as PNG, which keeps the file small; this is how Windows 10 and 11 store their own icons, with PNG only for 256. Images may be 1 to 256 pixels square. The default sizes are Windows 10 and 11's: 16, 20, 24, 32, 40, 48, 64 and 256.

Properties

Public property PngMinSize: Integer read FPngMinSize write FPngMinSize;

The smallest image size stored as PNG; 256 by default.

Images this size or larger are stored as PNG, smaller ones as bitmaps. Set it above 256 to store every image as a bitmap, for the oldest readers, or lower to make the file smaller; Windows Vista and later read either.
