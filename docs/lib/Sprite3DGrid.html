Description

Draws a far-reaching grid on a model's floor with a GLSL shader.

ShowModelGrid adds a TModelGrid to a TGorillaModel. It shows a grid of lines across one of the model's axes, Y by default, so the grid lies in X and Z. The lines are GridSize apart in the model's own units, 1.0 by default, in dark grey, with one through the model's centre of rotation, and the grid reaches GridCells cells each side of it, 1000 by default. Distant lines fade out as their cells shrink to a few pixels on screen, so the grid dissolves into the distance rather than stopping at an edge. GridLevel is where it crosses its axis; with GridOnFloor, the default, that is the model's floor, the bounding-box face across the grid's axis that is lower in the scene, the lowest point of the model's own geometry. For a model centred on its origin and reaching 1 each way that is -1 in Y; for a model standing on its origin it is 0. Give ShowModelGrid the box measured as the model was loaded, before any helper such as the axes is added, as Gorilla counts helpers in the model's bounds. Set GridLevel to put the grid elsewhere.

The grid is a single TGorillaPlane. The lines are worked out per pixel by GLSL code in its TGorillaDefaultMaterialSource, through its documented SurfaceShader hook, which Gorilla converts for Vulkan and Metal. The plane is split into 64 by 64 squares so that the position the shader reads stays exact across it; the cost is the same however far the grid reaches, the lines stay about two pixels wide at any distance, and nothing is recalculated per frame. Changing a grid property rewrites the shader once, with the new values written into it as constants.

On macOS and iOS, where Gorilla3D draws through Metal and does not support a material's SurfaceShader, the grid is instead one thin plane per line, reaching at most 20 cells each side of the centre, without the fade.

The plane is not a child of the model, so it never counts in the model's bounding box, and FitToBounds is unaffected. It sits in a frame beside the model that copies the model's position, rotation, scale and centre of rotation whenever they change, so the grid is in the model's units and moves with it. 

<model's parent>
|-- TGorillaModel
|   `-- TModelGrid       one per model, found by FindModelGrid;
|                        keeps the frame on the model's transform
`-- grid frame           TDummy copying the model's transform, owned by the TModelGrid
    `-- TGorillaPlane    turned onto GridAxis at GridLevel; grid drawn by its shader

Usage: 

Grid := ShowModelGrid(GorillaModel1);   // after the model is loaded and placed
if Grid <> nil then
  Grid.GridSize := 0.5;
HideModelGrid(GorillaModel1);

function ShowModelGrid(const AModel: TGorillaModel): TModelGrid; overload;

Shows a shader-drawn grid on AModel's floor, from its current bounds.

As the other ShowModelGrid, with AModel's current bounding box from GetAnimatedBoundingBox. Gorilla counts the model's children in that box, so any helper already added, such as the axes, can lower the floor; where the box measured as the model was loaded is to hand, pass it to the other ShowModelGrid instead.

Parameters
AModel
The model to show a grid for. Nothing happens if it is nil.
Returns

The new grid, owned by AModel; or nil, with nothing added, if AModel is nil or its bounding box is empty.

function ShowModelGrid(const AModel: TGorillaModel; const ABox: TBoundingBox): TModelGrid; overload;

Shows a shader-drawn grid on AModel's floor, the lowest face of ABox.

Any grid already on AModel is removed first, so calling it again, for example after loading a different model, rebuilds it for the new bounds. The floor is the face of ABox across the grid's axis that is lower in the scene, and one line each way passes through AModel.RotationCenter. Call it once the model is placed and turned, since the floor depends on the turn. The grid is added as a child of AModel and is freed with it. Call from the main thread only.

Parameters
AModel
The model to show a grid for. Nothing happens if it is nil.
ABox
The model's own bounds, in its own coordinates, best measured as it was loaded, before any helper was added to it.
