Declaration

type TSprite3DAnimationPlayer = class(TObject)

Description

Plays, pauses and steps one animation of a model on screen, an export frame at a time.

Made when the animation starts playing from its beginning. While it plays, the player keeps its own clock, so Pause can tell which frame is showing. Pause, Step and ShowFrame hold the animation on one frame: the frames are those an export at FrameRate makes, by TSprite3DAnimationFrames, so frame N is held exactly as frame N of an export shows it, from the baked pose where Gorilla has baked the animation. Play carries on from the frame held. Freeing the player lets a held animation play on.

For the main thread only. The model and animation must outlive the player, and nothing else, such as a capture, may drive the animation while it is held.

Methods

Public constructor Create(const AModel: TGorillaModel; const AAnimation: TGorillaAnimation; const AFrameRate: Integer; const AFrameCount: Integer = 0);

Starts following an animation that has just started from its beginning.

Parameters
AModel
The model the animation belongs to.
AAnimation
The animation, current and running from its first pose.
AFrameRate
The export frame rate, which sets the frames held and stepped through.
AFrameCount
The number of export frames, in place of what AFrameRate gives, such as one chosen by hand; 0, the default, for what AFrameRate gives. It is kept when FrameRate changes.
Exceptions raised
EArgumentException
If AModel or AAnimation is nil, or AFrameRate is below 1.
Public destructor Destroy; override;

Lets a held animation play on from its frame, then frees the player.

Carries on playing from the frame held; nothing if it is not held.

Holds the animation on the frame showing now; nothing if already held.

Public procedure ShowFrame(const AFrame: Integer);

Holds the animation on frame AFrame.

Parameters
AFrame
The frame, from 0 to FrameCount - 1; others wrap round, as the animation loops, so -1 is the last frame.
Public procedure Step(const ADelta: Integer);

Holds the animation ADelta frames on from the one held, or from the one showing if it is playing.

Parameters
ADelta
Frames to move: 1 for the next, -1 for the previous; it wraps round.

Public property FrameRate: Integer read FFrameRate write SetFrameRate;

The export frame rate the frames are counted at.
