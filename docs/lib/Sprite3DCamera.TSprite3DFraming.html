Unit

Sprite3DCamera

Declaration

type TSprite3DFraming = record

Description

A camera's framing: where it orbits and how far out it is.

Holds what FitToBounds and FitToBoundsMax change, so a fit can be undone. Angles are not included; a fit never changes them.

See also
TSprite3DCamera.SaveFraming
Returns the current framing, for RestoreFraming to put back later.
