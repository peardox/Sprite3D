Declaration

type TModelAxes = class(TDummy)

Description

Shows three coloured lines through a point, drawn on top or by shaders.

A TDummy. With OnTop it draws the lines in its own Render, in the main pass and grabs, with the context's DrawLine helper. Without OnTop it draws nothing itself: it owns a frame beside its parent holding six shader-drawn TGorillaPlane strips, and in each Render copies the parent's position, rotation, scale and centre of rotation to the frame if any of them changed. The strips are built when SetExtent is called and rebuilt only when a property changes. Freeing the TModelAxes frees the frame, strips and materials.

Its Width, Height and Depth are set to the lines' extent and its Position to their middle, so anything that culls by an object's size sees the whole set. The object is not stored in .fmx files and ignores the mouse. Use it from the main thread only.

Methods

Protected procedure Render; override;

Draws the lines on top, or keeps the strips' frame on the parent.

Does nothing before SetExtent is called. With OnTop, draws the three lines in the main pass and grabs, setting the context matrix to this object's AbsoluteMatrix and restoring the previous matrix, line state and depth test afterwards, even if drawing fails. Without OnTop, copies the parent's transform to the frame if it changed, and draws nothing.

Public procedure SetExtent(const ALow, AHigh, ACentre: TPoint3D);

Sets where the three lines cross and how far each reaches.

Each line passes through ACentre parallel to one axis and runs from the low corner's value to the high corner's value on that axis, widened if need be to reach ACentre. All points are in the parent's coordinates. Without OnTop the strips are built here, so set the parent first; they are not built without one. Redraws the axes.

Parameters
ALow
The corner with the smallest X, Y and Z, such as a bounding box's TopLeftNear.
AHigh
The corner with the largest X, Y and Z, such as a bounding box's BottomRightFar.
ACentre
The point the three lines cross.

Public property LineWidth: Single read FLineWidth write SetLineWidth;

Line width in screen pixels, whatever the distance; 1 by default.

Without OnTop the shader draws any width on every backend. With OnTop, values above 1 work on desktop OpenGL only; Vulkan, Metal and OpenGL ES always draw 1 pixel. Values below 1 count as 1.

Public property Shown: Boolean read FShown write SetShown;

Whether the helper is drawn at all; True by default.

False hides it, its lines and planes included, which are drawn beside the model rather than as children of this object, so Visible alone does not hide them. Nothing is freed, and True shows it again as it was. Kept when the drawing is rebuilt.

Public property OnTop: Boolean read FOnTop write SetOnTop;

Whether the lines are drawn over everything; True by default.

True draws them with the context and depth testing off, so the model and anything in front cannot hide them. False draws them with shaders as ordinary geometry, so they disappear where they pass inside a solid model or behind something. Changing it switches between the two at once.
