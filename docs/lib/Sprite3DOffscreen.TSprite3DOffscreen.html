Unit

Sprite3DOffscreen

Declaration

type TSprite3DOffscreen = class(TGorillaRenderPassController)

Description

A render pass that draws the viewport's scene off screen, one frame on request.

Create it, set Viewport to the TGorillaViewport to capture, then call Grab whenever an image is wanted. The pass uses the viewport's camera, lights and models as they are at the time of the frame. It takes over the inherited OnBeginRender, OnEndRender, BackgroundColor and Iterations, which must not be changed. All members are for the main thread only.

With TransparentBackground, the default, the background comes out transparent, with soft edges and see-through materials partly transparent, by difference matting: the frame is drawn twice, over black and over white. Where the two differ, the background showed through, by as much as they differ; the over-black image is then the colour already multiplied by that alpha, which is how FMX bitmaps hold it. This needs nothing from the renderer's own alpha, which Gorilla's passes do not keep. Both drawings are made in the same frame, as two iterations of the pass, so an animated model is caught in the same pose in both; if the renderer does not take the new clear colour between iterations, the pass finds the drawings identical and, from then on, draws them in frames one after the other instead. The first grab also draws over 50% grey, which shows whether the renderer gamma-encodes its output after blending; if it does, the matting is done in linear light, so soft edges keep their true alpha either way.

Protected function CreateMaterialSource(): TGorillaRenderPassMaterialSource; override;

Returns nil: this pass draws every object with its own materials.

Abstract in TGorillaRenderPassController, so it must be overridden. A pass's material source provides the shader for the RectToFBO method, or one material that every object is drawn with; this pass uses RenderListToFBO and must keep each model's own materials and textures, so it has none.

Returns

Always nil.

Public constructor Create(AOwner: TComponent; const AId: String = 'Sprite3DOffscreen'); override;

Creates the pass, switched off, with a 256 by 256 target.

The pass renders before the main pass, into its own frame buffer, with Gorilla's default rendering (order-independent transparency), and makes the background transparent. Nothing is drawn until Viewport is set and Grab is called.

Public function GrabSizes(const ASizes: array of Integer; const AOnGrabbed: TSprite3DGrabSizesProc): Boolean;

Grabs one square image of each size in turn, then passes them all to AOnGrabbed.

Does what Grab does once for each size, one frame after another: Width and Height are set to the size, OnBeforeGrab and OnAfterGrab run around each grab, so the camera can be fitted to each, and the images are collected. Afterwards Width and Height are put back as they were. Returns at once and does not block; AOnGrabbed runs once on the main thread when every size is done, or as soon as one fails. Busy is True throughout, as each grab starts the next; do not call Grab or Cancel until AOnGrabbed has run.

Parameters
ASizes
The widths, which are also the heights, in pixels; each at least 1.
AOnGrabbed
The procedure to call with the images; must not be nil.
Returns

True if the grabs were started; False, with nothing started, if a grab is already under way, Viewport is not set, ASizes is empty or AOnGrabbed is nil.

OVERSCAN_MAX wherever grabs are drawn off screen, as whatever the GPU cannot draw in one go is made up with shifted drawings; always 1 on macOS and iOS, where grabs are screenshots. The sizes are not otherwise used.

Public function SinglePassOverscan(const AWidth, AHeight: Integer): Integer;

How much of an overscan factor a grab of AWidth by AHeight can draw in one go here.

The enlarged target must fit what the GPU can draw, its largest texture, render buffer and viewport, OVERSCAN_TARGET_LIMIT, and any smaller size found not to draw this session, allowing for any display scaling the pass has met. The GPU's own limits are read during the first grab; before that the context class's largest texture is used, or 4096 if it gives none. Always 1 on macOS and iOS.

Parameters
AWidth
The grab's width in pixels.
AHeight
The grab's height in pixels.
Returns

1 to OVERSCAN_MAX.

Public property Backdrop: TSprite3DBackgroundSpec read FBackdrop write FBackdrop;

What grabs show behind the model when TransparentBackground is True.

None, the default, and Transparent leave the background transparent. Solid and Gradient fill it, after the matting, with the colour or with the gradient from GradientFrom to GradientTo in GradientDirection; soft edges blend into it as they would on screen. The checker settings are not used: the checker only stands for transparency on screen. Changes made while Busy apply from the next grab.

The target's height in pixels; 256 by default.

Published property TransparentBackground: Boolean read FTransparentBackground write FTransparentBackground default True;

Whether grabs have a transparent background; True by default.

True draws each grab twice, over black and over white, and works out each pixel's alpha from the difference, as described for the class, so the background is fully transparent and soft edges are partly so. False draws it once over OpaqueBackground, with every pixel opaque.

Published property OpaqueBackground: TAlphaColor read FOpaqueBackground write FOpaqueBackground default TAlphaColors.Black;

The background colour when TransparentBackground is False; black by default.

Its alpha is ignored: the background is always drawn opaque.

Published property Overscan: Integer read FOverscan write SetOverscan default 1;

How many times larger each way grabs are drawn before being scaled down; 1, the default, is off.

Values are limited to 1 to OVERSCAN_MAX. A grab draws as much of it as SinglePassOverscan allows in one go, and makes up the rest with shifted drawings, each slid through OnShiftView. Every drawing is matted, scaled down to Width by Height with Resample, and freed before the next, and the backdrop is filled in and the bitmap made only at the end, so OnBeforeGrab and the delivered image see only Width by Height. Changes made while Busy apply from the next grab.

Published property Resample: TSprite3DResampleFilter read FResample write FResample default rfBox;

The filter overscanned grabs are scaled down with; Box by default.

Changes made while Busy apply from the next grab.

Published property OnOverscanReduced: TSprite3DOverscanEvent read FOnOverscanReduced write FOnOverscanReduced;

Runs when an overscanned target turns out too large to draw, before the grab is made again smaller.

The size is remembered for the rest of the session, so MaxOverscan allows less from then on and later grabs do not try it again. Use it to tell the user. Runs on the main thread, outside the render loop; it must not call Grab or Cancel.

Published property OnShiftView: TSprite3DShiftViewEvent read FOnShiftView write FOnShiftView;

Slides the view by a fraction of a pixel for one of a grab's shifted drawings, or puts it back.

Called only when Overscan needs more than one drawing. Before each drawing, after OnBeforeGrab, it is called with the slide that drawing needs, a fraction of a pixel of the grab's own size in each direction, or 0 for none; after the drawing has been read, before OnAfterGrab, it is called with 0 and 0 to put the view back. The slides are spread evenly over a drawn pixel, so which way is right or up does not change the result. Without a handler the drawings are not slid and overscan beyond what can be drawn in one go only repeats work. Runs on the main thread, from inside the render for the putting back, and must only change scene state.

Published property OnBeforeGrab: TSprite3DGrabSizeEvent read FOnBeforeGrab write FOnBeforeGrab;

Runs in Grab, just before the frame is requested, to set the scene up for the target.

Use it to fit the camera to the target's shape, for example with TSprite3DCamera.FitToBounds(Model, AWidth, AHeight), so the model fills the grab. Whatever it changes is drawn into the target and must be put back in OnAfterGrab, which follows it: after the pass has drawn, before the main pass draws the same frame, or from Cancel if the frame never comes. It is not called if the pass is freed first. Runs on the main thread.

Published property OnAfterGrab: TNotifyEvent read FOnAfterGrab write FOnAfterGrab;

Runs once after an OnBeforeGrab, to put back what it changed.

Called from inside the render, just after the target has been drawn and read, so the main pass in the same frame shows the scene as before; or from Cancel if the frame never came. Not called if the pass is freed while a grab is waiting. Runs on the main thread, and must only change scene state, not show dialogs or call Grab.
