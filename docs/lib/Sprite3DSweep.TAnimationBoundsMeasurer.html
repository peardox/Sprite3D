Declaration

type TAnimationBoundsMeasurer = class(TObject)

Description

Measures a model's animations as MeasureAnimationBounds does, a few milliseconds at a time.

Create it for a model, then call Step repeatedly, for example from the main thread's queue with a frame or so between calls, until it returns True; Results then holds the same boxes MeasureAnimationBounds would have given. Each Step measures poses until its budget is spent, at least one, and before returning puts back the animation that was current, running or stopped as it was, released from any fixed pose, so the frames drawn between steps show the model as the user left it. It can stop part-way through an animation and carry on from there next time.

Gorilla counts a model's children in its animated bounds, so detach any child helper for the length of each Step. Do not change the model, or its animations, between steps, nor Step while something else drives the animations, such as a capture. Main thread only.

Methods

Public constructor Create(const AModel: TGorillaModel);

Prepares to measure every animation of AModel.

Counts the poses to measure, which is quick; nothing is measured until Step.

Parameters
AModel
The model; it must outlive the measurer, and be visible while it is measured, as MeasureAnimationBounds says. Nil, or a model without animations, gives a measurer that is already Finished, with no results.
Public destructor Destroy; override;

Frees the measurer; the model is left as the last Step left it.

Public function Step(const ABudget: Integer): Boolean;

Measures poses for up to ABudget milliseconds, then puts the model's animation back.

Blocks for about ABudget milliseconds, longer if one pose takes longer, as at least one is measured each call. Pass MaxInt to measure everything left in one go.

Parameters
ABudget
How long to measure for, in milliseconds.
Returns

True once every animation has been measured; Results is then complete.

Public function Results: TArray<TAnimationBounds>;

The boxes measured so far, one per finished animation, in the order GetSortedAnimations gives them.

Returns

A copy; complete once Finished.
