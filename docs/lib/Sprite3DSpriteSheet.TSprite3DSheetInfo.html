Fields

Public Width: Integer;

The whole image's width, in pixels.

Public Height: Integer;

The whole image's height, in pixels.

Public Cols: Integer;

The columns of the image's grid of cells.

Public Rows: Integer;

The rows of the image's grid of cells.

Public Origin: TPoint;

The pixel the centre of rotation falls on in a frame.

Public OriginKnown: Boolean;

False writes null for the origin, Origin being unused.

Public Directions: TArray<Double>;

The directions the image holds, as compass bearings in degrees, in the order they are exported; empty for the single dummy 0.

Public Animations: TArray<String>;

The names of the animations the image holds, in order.

Public AnimationFrames: TArray<Integer>;

How many frames each of Animations has in all, on this image or not.

Public Frames: TArray<TSprite3DFrameRef>;

For each of the image's frames, in order, which animation, direction and frame it is.

Public Meta: TSprite3DSheetMeta;

The meta section: page, credits, dates and model.
