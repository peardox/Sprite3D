Public constructor Create(const AConfigFile, AName, AFolder: String);

Reads the configuration and what has been downloaded; uses no network.

Parameters
AConfigFile
The JSON file of addresses; a missing or unreadable file means no address.
AName
The library's name for messages, such as 'OpenH264'.
AFolder
Where downloads are kept; created when the first is saved. Every file in it other than the current library and installed.json may be deleted.
Public destructor Destroy; override;

Cancels a download under way, waits for it to stop, and frees the object.

Public function Start(const AOnDone: TSprite3DLibraryUpdateDone): Boolean;

Downloads the library in the background if it is configured and not already current.

AOnDone is called once, on the main thread, when the download ends, unless it is cancelled. Nothing happens, and AOnDone is not called, if there is no address, the current copy is up to date, or a download has already been started by this object.

Parameters
AOnDone
Called with the new library's path, or an empty path and the reason.
Returns

True if a download was started.

Public procedure Cancel;

Stops a download under way without calling its procedure, and waits for it.
