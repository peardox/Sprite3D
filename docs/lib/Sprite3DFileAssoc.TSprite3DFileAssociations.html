Sprite3DFileAssoc

Declaration

type TSprite3DFileAssociations = class(TObject)

Description

Registers the running program for a set of file types, for the current user.

Create it, use it and free it; it holds no system resources between calls. Each method that changes something returns False on failure and leaves the reason in LastError.

See also

Public function Register: Boolean;

Offers this program under Open With for the types.

Registers again over an older registration, so the entries point at this copy of the program. On macOS it asks Launch Services to read the bundle again.

Returns

True on success; False, with LastError set, on failure or where the platform does not allow it.

Public function Unregister: Boolean;

Removes what Register added.

Call RestoreDefaults first if the program was made the default. Not possible on macOS, where the bundle declares the types.

Returns

True on success; False, with LastError set, otherwise.

Public function Claim: Boolean;

Makes this program the default for the types without asking, for types that are the application's own.

Only for file types no other program has a claim to, such as the application's own documents: it does not keep the previous defaults, as MakeDefault does. On Windows it sets each extension's own default ProgID in HKCU\Software\Classes, which a choice made in Windows' own How do you want to open dialog with Always still overrides; on Linux it sets each MIME type's default in mimeapps.list. Call Register first. On macOS the bundle's document types do this, so it does nothing.

Returns

True on success; False, with LastError set, on failure or where the platform does not allow it.

Public function MakeDefault(var ABackup: String): Boolean;

Makes this program the default for every type, recording the old defaults.

For each type not yet in ABackup, the current per-user default is added to it first, so calling this again never loses the original. On Windows a choice the user made in Windows' own dialog still wins; NeedsUserConfirmation is then set.

Parameters
ABackup
The caller's backup string, which this adds to; keep it for RestoreDefaults.
Returns

True on success; False, with LastError set, otherwise.

Public function RestoreDefaults(var ABackup: String): Boolean;

Puts back the defaults recorded by MakeDefault.

Only types still defaulting to this program are changed, so a choice the user has made since is kept. A recorded default is put back only if it is still valid; otherwise the per-user default is removed. On macOS, where a default cannot be removed, a type with no valid old default keeps this program and the reason is put in LastError. The entries dealt with are taken out of ABackup.

Parameters
ABackup
The backup string from MakeDefault; on return, what is left of it, normally empty.
Returns

True if every type was dealt with; False, with LastError set, otherwise.
