Description

Switches the whole application between FireMonkey's own default look and a named FMX style, at run time.

ApplyFmxStyle sets the style through TStyleManager, so it reaches every form that has no StyleBook of its own, including forms already on screen. A named style is looked for first as a resource linked into the program, then as a <name>.style file in each of the folders given, in order, with the file name matched regardless of case. An empty name puts back the platform's default style.

The styles that come with RAD Studio are in its Redist\styles\Fmx folder; copy the ones wanted next to the program, link them in as RCDATA resources, or deploy them with the application.

The unit knows nothing of any particular application. Call it on the main thread only.

function ApplyFmxStyle(const AName, AResourceName: String; const AFolders: array of String; out AError: String): Boolean;

Applies a named FMX style to the whole application, or puts back the default.

For a non-empty AName, AResourceName is tried first, if given, then <AName>.style in each of AFolders in turn; the first that loads is used. When none is found or none loads, the style in use is left as it was.

Parameters
AName
The style's file name without .style, such as Dark; empty for the platform's default style.
AResourceName
The name of an RCDATA resource holding the style, or empty to look for files only.
AFolders
The folders to look in for the style file, in order; empty entries are skipped.
AError
On failure, why; empty on success.
Returns

True if the style, or the default, is now in use.
