Description

Works out the volume a model sweeps as it turns about its up axis, for its rest pose and each animation, and draws the one in use.

CalcSweptVolume takes a bounding box and the model's centre of rotation and works out the space the box passes through in a full turn about a line through the centre of rotation, parallel to one of the model's own axes: Y, the model's up axis, by default. That space is a cylinder, or a thick-walled tube when the centre of rotation lies outside the box seen along the axis. Its outer radius reaches the box's farthest corner and its inner radius its nearest point; it is exactly as long as the box is along the axis. The swept box is the box that encloses the tube, square across the axis and centred on it. The result is a TSweptVolume, in the model's own coordinates. The box encloses the model, so the swept volume encloses everything the model can reach as it turns, with room to spare where the model does not fill its box.

An animation moves the model's vertices, so it can reach outside the rest pose's box. MeasureAnimationBounds steps each of the model's animations through every pose Gorilla has baked for it and returns, per animation, the box that holds all of its poses. Each of those boxes gives that animation's swept volume. For a model with many animations that takes a while, so TAnimationBoundsMeasurer does the same in steps of a few milliseconds, for a caller to run between frames while the application stays responsive.

FitCameraToSweep frames a swept volume with TSprite3DCamera.FitPointsOnAxis: it fills the view on the tighter axis, with the orbit centre on the turning axis, through the model's centre of rotation; the angles are left alone. CombinedSweptVolume gives the volume to fit, joining the rest pose's with that of each animation named, so a chosen subset of the animations can define it.

ShowCombinedSweep adds a TCombinedSweep that draws one fixed volume, such as the one CombinedSweptVolume gives, in fuchsia and hot pink, beside the per-animation sweep.

ShowModelSweep adds a TModelSweep holding the rest pose's volume and one per animation. Each frame it draws the volume of the animation the model is playing, or the rest pose's when none is playing or the playing one was not measured, so the wireframe changes as soon as another animation is played. It draws the swept box in aqua, and the tube's outer and inner walls, with the axis itself, in yellow. The lines are drawn with the context's DrawLines helper, two calls a frame, one per colour, following Gorilla v1.5's Line Rendering guide, with depth testing as usual, so the model hides the parts behind it. Widths above 1 pixel work on desktop OpenGL only; Vulkan, Metal and OpenGL ES always draw 1 pixel.

The swept box is larger than the model's own box, and Gorilla counts a model's children in its bounding box, so the TModelSweep is not a child of the model: it sits beside it, owned by the model so it is freed with it, and draws with the model's matrix. The model's own bounding box, ShowBoundingBox and the camera's fits are therefore unaffected. For the same reason, measure the boxes before adding any helper that is a child of the model. 

<model's parent>
|-- TGorillaModel     owns the TModelSweep, so frees it
`-- TModelSweep       one per model, found by FindModelSweep; draws the volume in use in
                      its Render with the model's AbsoluteMatrix

Usage: 

Box := GorillaModel1.GetBoundingBox();            // before any helper is added
Anims := MeasureAnimationBounds(GorillaModel1);   // blocks; changes the pose meanwhile
Sweep := ShowModelSweep(GorillaModel1, Box, Anims);
if Sweep <> nil then
  Memo1.Lines.Add(Sweep.Volume.ToString);
HideModelSweep(GorillaModel1);

function CalcSweptVolume(const ABox: TBoundingBox; const APivot: TPoint3D; const AAxis: TSweepAxis = saY): TSweptVolume;

Works out the space a bounding box passes through in a full turn about an axis.

The turn is about the line through APivot parallel to the model's AAxis. Seen along that axis the box is a rectangle: OuterRadius is the distance from the axis to its farthest corner and InnerRadius to its nearest point, 0 if the axis passes through it. The volume runs along the axis exactly as far as the box does. Pure arithmetic; any thread.

Parameters
ABox
The box, in the model's own coordinates. Measure it before any helper is added to the model as a child, as Gorilla counts children in its bounds.
APivot
A point the axis passes through, normally the model's centre of rotation, RotationCenter.Point, in the same coordinates.
AAxis
Which of the model's axes the turn is parallel to; Y, its up axis, by default.
Returns

The swept volume; Valid is False if ABox is empty, with a minimum above its maximum on any axis.

function MeasureAnimationBounds(const AModel: TGorillaModel): TArray<TAnimationBounds>;

Measures, for each of AModel's animations, the box that holds all its poses.

Each animation in turn is made current and stepped, with TSprite3DAnimationFrames, through one cycle at the rate Gorilla baked its poses, 30 frames a second if it baked none, and after each step the model's GetAnimatedBoundingBox is added to that animation's box. The animation that was current before is made current again afterwards, running or stopped as it was; the others are left stopped. The model's pose changes while this runs, and is wherever the restored animation puts it afterwards.

Blocks for as long as the stepping takes: the number of poses times the cost of one bounding box. Do not call it while something else drives the animations, such as a capture. Gorilla counts a model's children in its animated bounds, so call it before adding any helper to AModel as a child. Main thread only.

An animation whose poses Gorilla did not bake is posed by seeking its skeleton; on Delphi 13 and later that pose is only evaluated when a frame is drawn, so such an animation's box may be that of the pose already showing. Sprite3D loads models with vertex caching, so its animations are baked.

Parameters
AModel
The model; nil, or one with no animations, gives an empty array.
Returns

One entry per animation that gave a non-empty box, in the order GetSortedAnimations gives them.

function UnionSweptVolume(const AVolumes: array of TSweptVolume): TSweptVolume;

The smallest swept volume that holds every valid volume given.

The volumes must turn about the same axis through the same pivot, as those worked out for one model are; the result takes both from the first valid volume. Its length runs from the lowest AxialLow to the highest AxialHigh, its outer radius is the largest and its inner radius the smallest. Where the volumes differ in length the result is a little larger than their union, never smaller. Pure arithmetic; any thread.

Parameters
AVolumes
The volumes; those that are not Valid are skipped.
Returns

The combined volume; Valid is False if none of AVolumes is Valid.

function CombinedSweptVolume(const AModel: TGorillaModel; const ABox: TBoundingBox; const AAnimations: TArray<TAnimationBounds>; const ANames: TArray<String>; const AIncludeRest: Boolean = True; const AAxis: TSweepAxis = saY): TSweptVolume;

The swept volume of a model over its rest pose and a chosen set of its animations.

Works out the rest pose's volume from ABox and each chosen animation's from its entry in AAnimations, all about the line through AModel.RotationCenter parallel to AAxis, and combines them with UnionSweptVolume. Only the animations named in ANames are included, so a fit can be made for a subset of them; pass every Id for all of them, and none for the rest pose alone. A name with no entry in AAnimations is skipped. Main thread only, as it reads AModel.

Parameters
AModel
The model; nil gives a volume that is not Valid.
ABox
AModel's own bounds at rest, measured before any helper was added to it as a child.
AAnimations
The boxes MeasureAnimationBounds gave for AModel's animations; may be empty.
ANames
The Ids of the animations to include; empty for none.
AIncludeRest
Whether the rest pose's volume is included.
AAxis
Which of the model's axes it turns about; Y, its up axis, by default.
Returns

The combined volume; Valid is False if nothing chosen gave a box.

function SweepOutline(const AVolume: TSweptVolume; const ASegments: Integer = 64): TArray<TPoint3D>;

Points whose convex hull holds the whole of a swept volume.

Two rings of ASegments points, one at each end of the volume, on a regular polygon drawn round the outer circle rather than inside it, so the polygon, and every view of it, holds the circle. From any direction the volume's outline is that of its two end circles, so these points are all a camera fit needs. Pure arithmetic; any thread.

Parameters
AVolume
The volume, in the model's own coordinates.
ASegments
Points in each ring; values below 8 count as 8. 64 makes the polygon at most 0.12% wider than the circle.
Returns

2 times ASegments points in the model's own coordinates; empty if AVolume is not Valid.

function FitCameraToSweep(const ACamera: TSprite3DCamera; const AModel: TControl3D; const AVolume: TSweptVolume; const AMargin: Single = 0): Boolean; overload;

Frames a model's swept volume as large as it will go, with the orbit centre on its turning axis.

The volume's outline, by SweepOutline, is framed with ACamera.FitPointsOnAxis: as large as it will go for the current angles, centred, so it reaches both edges of the tighter axis, with the orbit centre then put on the turning axis, the line through the model's centre of rotation, carried through AModel's transform. Azimuth, PolarAngle and Roll are not changed. The volume holds the model in every turn about its axis, so turning the model about that axis, or the camera's azimuth about it when the two axes are parallel, never takes the model out of view; nor does any animation whose bounds the volume includes. Main thread only.

Parameters
ACamera
The camera to fit; nil makes the call return False.
AModel
The model the volume belongs to; its transform carries the volume into the scene. Nil makes the call return False.
AVolume
The volume, in AModel's own coordinates, such as one from CombinedSweptVolume.
AMargin
Padding as a fraction of the view: 0.1 makes the volume 1/1.1 of the view on the tighter axis.
Returns

True if the volume was framed; False, with nothing changed, if ACamera or AModel is nil, AVolume is not Valid, the camera is locked, there is no viewport, or it has zero width or height.

function FitCameraToSweep(const ACamera: TSprite3DCamera; const AModel: TControl3D; const AVolume: TSweptVolume; const AViewWidth, AViewHeight: Single; const AMargin: Single = 0): Boolean; overload;

Frames a model's swept volume for an explicit view size.

As the other FitCameraToSweep, for a view of AViewWidth by AViewHeight instead of the viewport's size; only their ratio matters. Use it for an off-screen target whose shape differs from the viewport's.

function ShowModelSweep(const AModel: TGorillaModel; const ABox: TBoundingBox; const AAnimations: TArray<TAnimationBounds>; const AAxis: TSweepAxis = saY): TModelSweep; overload;

Draws the volume AModel sweeps in a full turn about its up axis, at rest and in each animation.

Any sweep already on AModel is removed first, so calling it again, for example after loading a different model, redraws it for the new bounds. The volumes are worked out by CalcSweptVolume, about the line through AModel.RotationCenter parallel to AAxis: the rest pose's from ABox, and each animation's from its entry in AAnimations. While AModel plays one of those animations its volume is drawn; otherwise the rest pose's. The TModelSweep is owned by AModel, so it is freed with it, and placed beside it, under AModel's parent. The volumes are worked out at the time of the call; call again if the centre of rotation changes. Call from the main thread only.

Parameters
AModel
The model to sweep. Nothing happens if it is nil or has no parent.
ABox
AModel's own bounds at rest, in its own coordinates, measured before any helper was added to it as a child.
AAnimations
The boxes MeasureAnimationBounds gave for AModel's animations; may be empty.
AAxis
Which of the model's axes it turns about; Y, its up axis, by default.
Returns

The new sweep, owned by AModel; or nil, with nothing added, if AModel is nil or has no parent, or ABox is empty and no animation gave a box.

See also

function ShowCombinedSweep(const AModel: TGorillaModel; const AVolume: TSweptVolume): TCombinedSweep;

Draws one fixed swept volume beside AModel, such as the combined volume of its rest pose and the animations used.

Any combined sweep already on AModel is removed first, so calling it again redraws it for the new volume. The TCombinedSweep is owned by AModel, so it is freed with it, and placed beside it, under AModel's parent; it draws AVolume whatever AModel plays. It is separate from the sweep ShowModelSweep adds, so both can be shown. Call from the main thread only.
