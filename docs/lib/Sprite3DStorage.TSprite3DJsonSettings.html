Declaration

type TSprite3DJsonSettings = class(TPersistent)

Description

Base class for settings kept as a JSON file.

Declare each setting as a published property of a descendant, with its default set in the constructor; Load fills them from the file and Save writes them all back. The JSON member names are the property names in camel case, such as saveFolder for SaveFolder. Only published properties are stored, so public ones, such as FileName, are not. Settings missing from the file keep their defaults and members in the file that no property matches are ignored, so a newer or older file still loads.

Not thread-safe; use one object from one thread, normally the main thread.

Public constructor Create(const AFileName: String); virtual;

Creates the settings with their defaults, for the given file.

Nothing is read until Load is called, and the file and its folder are not created until Save.

Parameters
AFileName
The full path of the JSON file.
Public function Load: Boolean;

Reads the settings from FileName.

Blocks while the file is read. If the file does not exist, which is normal on the first run, or cannot be read or parsed, the settings are left as they were and nothing is raised; a damaged file is replaced at the next Save.

Returns

True if the file was read; False if it was missing or unusable.

Public procedure Save;

Writes all the settings to FileName, creating its folder if needed.

Blocks while the file is written. The JSON goes to a temporary file beside FileName, which then replaces it, so a failure part-way leaves the previous file whole.

Exceptions raised
Exception
If the folder cannot be created or the file cannot be written; the class depends on the cause.
