Description

Resamples RGBA pixels to another size with a choice of filters, for overscanned grabs.

ResamplePixels scales an image held as RGBA bytes, four to a pixel, rows one after another, with one of the filters in TSprite3DResampleFilter. It is meant for overscan: rendering a grab at a whole multiple of its size and scaling it back down, which smooths edges and fine detail far better than the renderer's own anti-aliasing. It works in either direction and for any pair of sizes, though shrinking is what it is for.

The pixels must be premultiplied, colour already multiplied by alpha, as Sprite3D's grabs and FMX bitmaps hold them. Filtering premultiplied values keeps transparent pixels from bleeding their hidden colour into the edges round them. Filters with negative lobes can ring; each result is clamped to 0 to 255, and each colour to its alpha, so it stays a valid premultiplied pixel.

The work is separable: each row is resampled across, into a buffer of single-precision values the new width by the old height, then each column down. A filter reaches a number of source pixels that grows with the scale, so shrinking by 16 with Lanczos 3 reads 96 source pixels each way for every result. 

Filter      reach in output pixels   character
Box         0.5                      area average: exact for whole multiples
Bilinear    1                        tent: soft
CatmullRom  2                        bicubic: sharp, slight ringing
Mitchell    2                        bicubic: balanced
Lanczos3    3                        windowed sinc: sharpest, most ringing

function ResamplePixels(const ASource: TBytes; const ASourceWidth, ASourceHeight, AWidth, AHeight: Integer; const AFilter: TSprite3DResampleFilter): TBytes;

Scales premultiplied RGBA pixels to a new size with AFilter.

ASource holds ASourceWidth by ASourceHeight pixels, four bytes each in the order R, G, B, A, rows one after another, with colour already multiplied by alpha. Which way up the rows run does not matter, as the result keeps the same order. Every result is clamped to 0 to 255 and each colour to its alpha. Source pixels past an edge count as the edge pixel. Blocks while it works; any thread, as it touches nothing shared.

Parameters
ASource
The pixels to scale.
ASourceWidth
The source's width in pixels; at least 1.
ASourceHeight
The source's height in pixels; at least 1.
AWidth
The result's width in pixels; at least 1.
AHeight
The result's height in pixels; at least 1.
AFilter
The filter to scale with.
Returns

AWidth by AHeight pixels in the same layout; a copy of ASource if the sizes are the same.

Exceptions raised
EArgumentException
If a size is less than 1 or ASource is not ASourceWidth by ASourceHeight pixels long.

Types

TSprite3DResampleFilter = (...);

The filter ResamplePixels scales with.

Values
  • rfBox: Area average: each result is the mean of the source pixels it covers.

    Exact for a whole-number scale, such as overscan, with no ringing.

  • rfBilinear: Tent filter, reaching one output pixel each way: soft.
  • rfCatmullRom: Catmull-Rom cubic, reaching two output pixels each way: sharp, with slight ringing.
  • rfMitchell: Mitchell-Netravali cubic, B = C = 1/3, reaching two output pixels each way: a balance of sharpness and ringing.
  • rfLanczos3: Lanczos windowed sinc, reaching three output pixels each way: the sharpest, with the most ringing.
