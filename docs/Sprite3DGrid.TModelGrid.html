Declaration

type TModelGrid = class(TDummy)

Description

Shows a shader-drawn grid for its parent model.

A TDummy that draws nothing itself. It owns a frame beside its parent, holding the TGorillaPlane the grid is drawn on, and in each Render copies the parent's position, rotation, scale and centre of rotation to the frame if any of them changed. The plane and its material are built when SetExtent is called and rebuilt only when a grid property changes. Freeing the TModelGrid frees the frame, plane and material.

The object is not stored in .fmx files and ignores the mouse. Use it from the main thread only.

Public constructor Create(AOwner: TComponent); override;

Creates a grid with no extent: across Y, on the floor, lines 1.0 apart.

The colour is dark grey and the grid reaches 1000 cells each side. Nothing is built until SetExtent is called.

Parameters
AOwner
The owner, or nil to leave freeing to the parent.
Public destructor Destroy; override;

Frees the grid, with its frame, plane and material.

If the frame's parent is already being freed, as when the whole scene closes, the frame is left for it to free.

Public procedure SetExtent(const ALow, AHigh, ACentre: TPoint3D);

Gives the model's bounds and centre of rotation, and builds the grid.

All points are in the parent's coordinates. The grid is centred on ACentre in its plane, and with GridOnFloor its level is picked from the bounds. Set the parent first: the grid needs it, and is not built without one.

Parameters
ALow
The bounding box's corner with the smallest X, Y and Z.
AHigh
The bounding box's corner with the largest X, Y and Z.
ACentre
The centre of rotation; one line passes through it each way.
Public procedure UpdateGrid;

Picks the floor again, if GridOnFloor, and rebuilds the grid.

The floor depends on how the parent is turned, and is only picked when the grid is built or a grid property changes. Call this after turning the parent. Moving or scaling the parent needs no call.

Properties

Public property GridAxis: TGridAxis read FGridAxis write SetGridAxis;

The axis the grid is drawn across; gaY by default, so it lies in X and Z.

With GridOnFloor the floor is picked again for the new axis.

Public property GridSize: Single read FGridSize write SetGridSize;

Distance between grid lines in the parent's units; 1.0 by default.

One line passes through the centre of rotation and the rest are whole multiples of GridSize from it. The grid scales with the parent. Zero or less hides the grid.

Public property GridColor: TAlphaColor read FGridColor write SetGridColor;

Colour of the grid lines; dark grey, $FF404040, by default.

Its alpha scales the lines' opacity.

Public property GridLevel: Single read FGridLevel write SetGridLevel;

Where the grid crosses its axis, in the parent's units; 0 with no other information.

Every point on the grid has this value on GridAxis. While GridOnFloor is True it is set to the floor whenever the grid is built. Setting it yourself turns GridOnFloor off, so your value is kept.

Public property GridOnFloor: Boolean read FGridOnFloor write SetGridOnFloor;

Whether GridLevel follows the model's floor; True by default.

The floor is the face of the bounding box, across GridAxis, that is lower in the scene once the parent's transform is applied; FMX's Y points down, so that is the one with the larger scene Y. If neither is lower, because GridAxis is level in the scene, the face with the smaller value is used. This assumes the model stands on its lowest bound, which is true of the test animation but not of every model.

Public property GridCells: Integer read FGridCells write SetGridCells;

How many grid cells reach out each side of the centre; 1000 by default.

The plane is 2 * GridCells * GridSize across, so 2000 units square by default. Lines fade out as their cells shrink to a few pixels on screen, so the grid normally dissolves into the distance before its edge is seen; the last tenth also fades, with a straight edge. The cost does not depend on this value. Values below 1 count as 1.
