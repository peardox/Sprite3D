Class TControl3DAccess

Hierarchy

Unit

Sprite3DHelpers

Declaration

type TControl3DAccess = class(TControl3D)

Description

Protected-access helper for TControl3D; nothing in the project uses it yet.

Casting a TControl3D to this class exposes its protected members inside the unit that declares the cast. Because it is in the interface section, other units can use it too.
