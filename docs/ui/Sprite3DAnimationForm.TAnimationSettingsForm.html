Public procedure ShowAndFree;

Shows the dialog without blocking and frees it when it closes.

For Android and iOS, where ShowModal cannot block. OnAccept is called if it closes with OK, OnCancel otherwise.

Properties

Public property Fps: Integer read GetFps write SetFps;

The frame rate shown, in frames per second.

Set it before showing the dialog; read it after OK. Values are limited to ANIMATION_FPS_MIN to ANIMATION_FPS_MAX.

Public property MaxOverscan: Integer read FMaxOverscan write SetMaxOverscan;

The largest overscan factor allowed; OVERSCAN_FACTOR_MAX until set.

Set it before Overscan, to what the off-screen renderer can do, such as TSprite3DOffscreen.MaxOverscan. The slider stops there. Below OVERSCAN_FACTOR_MIN, overscan cannot be used: the tick box is cleared and disabled, and the note says so. Values above OVERSCAN_FACTOR_MAX count as OVERSCAN_FACTOR_MAX.

Public property OverscanEnabled: Boolean read GetOverscanEnabled write SetOverscanEnabled;

Whether the Overscan box is ticked.

Setting it True has no effect while MaxOverscan is below OVERSCAN_FACTOR_MIN.

Public property Overscan: Integer read GetOverscan write SetOverscan;

The overscan factor shown; limited to OVERSCAN_FACTOR_MIN to MaxOverscan.

It keeps its value while the box is not ticked, so it can be kept as a setting.

Public property Filter: TSprite3DResampleFilter read GetFilter write SetFilter;

The resampling filter chosen.

Public property AtlasPageSize: Integer read GetAtlasPageSize write SetAtlasPageSize;

The largest a texture atlas page may be each way, in pixels; one of ATLAS_PAGE_SIZES.

A value that is not one of them shows as the nearest that is.

Public property AtlasNonPowerOf2: Boolean read GetAtlasNonPowerOf2 write SetAtlasNonPowerOf2;

Whether texture atlas pages may be any size, rather than powers of 2.

Public property OnAccept: TNotifyEvent read FOnAccept write FOnAccept;

Public property OnCancel: TNotifyEvent read FOnCancel write FOnCancel;

Called on Cancel, or any close but OK, when shown with ShowAndFree.
