Unit Sprite3DAnimationsUsedForm

Description
Classes, Interfaces, Objects and Records

Description

The Model, Animations Used dialog: which of the model's animations are used.

A list of the model's animations, each with a tick box, and an All tick box above it that ticks or clears every one; it shows ticked only while every animation is ticked. The caller fills the list with SetAnimations and, after OK, reads UsedAnimations.

A column on the right gives each animation's own swept volume as a percentage of the combined swept volume: the rest pose's joined with that of every animation ticked at the time. It is worked out again whenever a tick changes. An animation that reaches much further than the others stands out, as the others' percentages are small beside it, and unticking it shows how much the combined volume shrinks without it. An unticked animation can show more than 100%, as it is not in the combined volume. Cancel, or closing the dialog any other way, leaves the caller's set as it was, as the dialog only changes its own copy. Keeping the set, and what it is used for, is the caller's job.

On the desktop, show it with ShowModal and read UsedAnimations afterwards; on Android and iOS, which cannot block, show it with ShowAndFree, which calls OnAccept on OK, OnCancel otherwise, and frees the form when it closes. For the main thread only.
