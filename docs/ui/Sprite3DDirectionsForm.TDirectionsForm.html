Public procedure FacePaintBoxMouseDown(Sender: TObject; Button: TMouseButton; Shift: TShiftState; X, Y: Single);

While the order is being changed, gives the clicked marker the next number.

A click near the ring of markers picks the nearest one; one already numbered, or a click near the centre, is ignored. The first one picked becomes the red marker, the dial turning onto it. When every marker is numbered, that becomes the order.

Properties

Public property Count: Integer read FCount write SetCount;

The number of directions; one of DIRECTION_COUNTS.

A value that is not one of them becomes the nearest that is. Setting it gives the plain order, clockwise unless the order was plainly anticlockwise; set Order after it.

Public property Start: Single read FStart write SetStart;

The red marker's bearing, in degrees clockwise from north.

Written values are rounded to the nearest degree, or to the nearest step if Snap is True, and wrapped into 0 up to 360. Change Order may leave it on another marker's bearing, which need not be a whole degree.

Public property Order: TArray<Integer> read FOrder write SetOrder;

The order the directions are taken in: for each, from the first, its position, counted clockwise from 0 at the red marker.

A value that is not every position from 0 to Count - 1 once each is ignored, leaving the order as it was. Reading gives a copy.

Public property Clockwise: Boolean read GetClockwise;

False only when the order is plainly anticlockwise from the red marker.

Public property Snap: Boolean read FSnap write SetSnap;

Whether the dial is locked to steps of one direction, counted from north.

Setting it True moves Start to the nearest step.

Public property Folder: String read FFolder write FFolder;

The folder Import and Export open in; left at the folder of the last file they used.

Empty opens wherever the system chooses. Read it back after the dialog closes, whether with OK or Cancel, to remember it.

Public property OnAccept: TNotifyEvent read FOnAccept write FOnAccept;

Called on OK when shown with ShowAndFree.
