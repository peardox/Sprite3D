Unit

Sprite3DBackgroundForm

Declaration

type TBackgroundSettingsForm = class(TForm)

Description

The Background Settings dialog; edits a TSprite3DBackgroundSpec.

Create it and set Spec. On the desktop, call ShowModal and, if it returns mrOk, read Spec, then free the form. Where ShowModal cannot block, as on Android and iOS, set OnAccept and call ShowAndFree instead. For the main thread only.

Public procedure ShowAndFree;

Shows the dialog without blocking, and frees it when it closes.

For platforms where ShowModal cannot block, such as Android and iOS. When the dialog closes with OK, OnAccept is called while Spec can still be read; then the form frees itself, so do not use it after that.

Properties

Public property Spec: TSprite3DBackgroundSpec read FSpec write SetSpec;

The background being edited: set it before showing, read it after OK.

Setting it shows its style, colours and checker size. The checker colours are kept as given; this dialog does not change them.

Public property OnAccept: TNotifyEvent read FOnAccept write FOnAccept;

Called after ShowAndFree when the dialog closes with OK; read Spec in it.
