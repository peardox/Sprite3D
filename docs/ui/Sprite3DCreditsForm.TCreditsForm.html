Public procedure ShowAndFree;

Shows the dialog without blocking and frees it when it closes.

For Android and iOS, where ShowModal cannot block. OnAccept is called if it closes with OK.

Properties

Public property Credits: TSprite3DCredits read GetCredits write SetCredits;

The credits shown; read them after OK.

Written, a Created that is not a yyyy-mm-dd date shows as today. Read, the text is trimmed and Created is the date shown, as yyyy-mm-dd.
