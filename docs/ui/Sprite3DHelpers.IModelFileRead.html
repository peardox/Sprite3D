Declaration

type IModelFileRead = interface(IInterface)

Description

A read of a model file on a worker thread, from StartModelFileRead.

Every member may be called from the main thread while the read goes on. The worker holds its own reference, so letting go of this one, or cancelling, never leaves it reading freed memory.
