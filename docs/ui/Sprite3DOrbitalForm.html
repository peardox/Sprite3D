Description

The Variable camera dialog: dials for the camera's angles, a distance slider and an optional pan.

Three dials set Azimuth, Inclination and Roll, whose readouts show whole degrees and, beside the Roll dial, the same three angles to six decimal places; a slider moves the camera out from the fitted distance, and, below them, the Pan box switches on two sliders that move the view along the model's own X and Z axes, the directions that are not the model's up. Pan is off by default and is meant for the odd case where the model should sit off centre; it moves the point the camera orbits, on top of the fit, and leaves the angles and the distance alone. Centre puts both sliders back to 0.

The dialog only edits a TCameraSettings. It never touches the camera itself: each change calls OnPreview, so the owner can show it at once, and the owner keeps or undoes the change when the dialog closes. On the desktop show it with ShowModal and free it afterwards; on Android and iOS, which cannot block, show it with ShowAndFree, which calls OnAccept on OK, OnCancel otherwise, and frees the form when it closes.
