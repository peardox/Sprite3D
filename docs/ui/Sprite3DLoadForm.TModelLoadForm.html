Shows how far the load has got and what it is doing.

Ignored once Abort has been asked for, so the dialog keeps saying it is aborting.

Parameters

How far, from 0 to 1; values outside are clamped.
AStatus
What is happening now, in a few words.
Public procedure Finish;

Closes the dialog, as the load has ended.

Shown with ShowModal, ShowModal returns and the caller frees the dialog; shown with ShowAndFree, the dialog frees itself, so it must not be used afterwards.

Public procedure ShowAndFree;

Shows the dialog without blocking and frees it when Finish closes it.

For Android and iOS, where ShowModal cannot block.
