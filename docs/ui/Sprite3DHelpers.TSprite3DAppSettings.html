Sprite3DHelpers

Declaration

type TSprite3DAppSettings = class(TSprite3DJsonSettings)

Description

The application's settings, kept between sessions in settings.json.

Create it, call Load once at start-up, and call Save after changing a setting. The file is settings.json in SupportFolder; on the first run it does not exist yet, so every setting keeps its default until the first Save. For the main thread only.

Methods

Public constructor Create; reintroduce;

Creates the settings with their defaults, for settings.json in SupportFolder.

Nothing is read until Load is called.

Public class function SupportFolder: String; static;

The application's per-user folder, for settings.json and support files.

AppDataFolder for APP_NAME: for example %APPDATA%\Sprite3D on Windows. It is created by the first Save.

Returns

The folder's full path, without a trailing path delimiter.

Public function HasSaveFolder: Boolean;

True if SaveFolder is set and the folder still exists.

False on the first run, and also if the folder has been removed or is on a drive that is not connected, so the user can be asked for a folder again.

Returns

Whether grabs can be saved in SaveFolder without asking.

The background settings together, as the viewport and grabs use them.

Reading turns the stored colour texts back into colours; one that cannot be read takes its default. Writing stores all of them; call Save afterwards to keep them.
