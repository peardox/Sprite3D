Unit Sprite3DDirectionsForm

Description

The Model, Directions dialog: how many directions there are around the model, where they point, and the order they are taken in.

The dialog shows a compass as a clock face: a white disc with N, E, S and W round its edge, and a marker at each of the directions' positions, spread evenly round it. The clock's "12 o'clock", the position the dial turns, is red; the others are black. Each marker shows its direction's number, from 1, when there are 32 or fewer. In the centre an arc with an arrowhead, half the diameter of the face, shows the way the numbers increase when they go clockwise or anticlockwise; for any other order the centre says Custom order. 

TDirectionsForm
|-- FacePaintBox          the compass, drawn in FacePaintBoxPaint; clicked to order
|-- CountCombo            1, 2 and every multiple of 4 or 6 up to 64
|-- ClockwiseRadio,
|   AnticlockwiseRadio,
|   CustomRadio           the order: plain either way, or set with Change Order
|-- StartDial             the red position's bearing, StartText showing it
|-- SnapCheck             locks the dial to steps of one direction
`-- CancelButton, ImportButton, OrderButton, ExportButton, OkButton

Change Order lets any order be chosen: the markers are clicked in the order wanted, and each takes the next number as it is clicked; once every marker has one, that is the order, shown by the Custom button. The first marker clicked becomes the red marker: if it is not the red one already, the dial turns onto it at once. Clicking Change Order again before the end, changing the number of directions, or choosing Clockwise or Anticlockwise, abandons it and turns the dial back. Positions are counted clockwise from 0 at the red marker, so Order, for each direction from the first, gives the position it is at: clicking E, S, W, N, SE, SW, NW and NE of eight that started with N red turns the red marker to E, at 90 degrees, and gives 0, 2, 4, 6, 1, 3, 5, 7. Order can also be set, say from a file, with the first direction elsewhere than the red marker: 2, 4, 6, 0, 3, 5, 7, 1 with the red marker at north is the same set of bearings.

Artwork bought or drawn elsewhere often comes with its directions in a fixed order of its own, which may need setting again and again, so Export writes everything the dialog holds to a JSON file, with SaveDirectionsFile, and Import reads one back, with LoadDirectionsFile, into the dialog; OK then keeps it as usual. Export and Import are on the desktop only, and open in Folder, which they leave at the folder last used.

The bearing is in degrees clockwise from north, which is at the top of the face. The dial sets it to any whole degree, or, with SnapCheck ticked, to a whole number of the steps between directions, counted from north; StartText names it when it is on one of the 32 points of the compass, such as NE or NbE. The dialog only edits its own copy: set Count, Start, Order and Snap before showing it and read them back after OK. On the desktop show it with ShowModal; on Android and iOS, which cannot block, show it with ShowAndFree, which calls OnAccept on OK and frees the form when it closes. For the main thread only.
