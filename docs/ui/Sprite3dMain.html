Description

Demo form for TSprite3DCamera: loads a model and drives the camera with dials.

The form has two tabs. The View tab holds a TGorillaViewport, created at run time, and a panel of three dials for Azimuth, inclination and Roll. The Debug tab holds a memo for log output. Below the Camera submenu, the View menu has five items that are ticked or not, each switched by choosing it: Show bounding box shows the model's bounding box, Show grid a grid on the model's floor, Show axes its own X, Y and Z axes through its centre of rotation, Fit any angle chooses how the model is fitted, and Orthographic switches between perspective and orthographic projection.

The camera starts in the isometric view, and each readout always shows its dial's angle, from 0 to 359 degrees. Azimuth is sent to the camera reversed, 360 minus the readout, so the view turns the right way for the dial. View, Camera, Variable lets the dials set the angles; View, Camera, Isometric, the default for now, sets the readouts to inclination 35.264, azimuth 45 and roll 0, the true isometric view, and switches the dials off; View, Camera, Pixel 2:1 does the same with an inclination of about 26.565; View, Camera, 3/4 View uses 45 degrees through the orthographic camera; View, Camera, Head On and View, Camera, Top Down use inclinations of 0 and 90 at azimuth 0; and View, Camera, Side View uses inclination 0 at azimuth 90. A test slider along the bottom of the 3D view moves the camera out from the fitted distance, x1 to x20.

On show, the form loads the model the operating system asked it to open, as when a .glb or .gltf file is double-clicked in Explorer or Finder, or else the model whose file FormShow names; files the system asks to open later replace it. File, OpenModel then loads any other glTF, FBX, OBJ, USD, Collada, STL or PLY file, and File, Exit closes the application. File, Grab renders the view off screen at 256 by 256 pixels, with the model fitted to fill it, and saves it as the next of grab001.png, grab002.png and so on in SaveFolder, asking for that folder only when none is known: SaveFolder is kept between sessions in settings.json, through TSprite3DAppSettings in Sprite3DHelpers. File, Save As Icon renders the view off screen at each of Windows' icon sizes and saves them together as one .ico file the user names. Behind the model the viewport can show a background; by default none is drawn. File, Background Settings... chooses None, Transparent (a two-grey checker standing for transparency), Solid or Gradient, which grabs and icons follow too.

Each model replaces the last: it plays its last animation by name if it has any, is centred and turned 180 degrees about X, and the camera is fitted so it fills the view. The model is refitted when the viewport is resized, the projection changes or View, Fit any angle is chosen, but not when a dial turns. Ticked, that item uses FitToBoundsMax, which frames the model for every angle at once, so the dials can never push it out of view. Not ticked, FitToBounds frames it exactly for the angles at the time of the fit, and turning a dial afterwards can push part of it past the edge until the next refit.

The form only handles the user interface. The 3D work is done by the library units in lib: Sprite3DCamera, Sprite3DAxes, Sprite3DGrid and Sprite3DOffscreen. The application's other rules, such as where models are found, how a model is loaded and placed, and how grabs are named and saved, are in Sprite3DHelpers.

On Android and iOS, where FMX shows no menu bar, the same menus are reached through a hamburger button on a toolbar at the top, which opens a drawer listing every item in MainMenu1; ticks show the current camera view and which View items are on. Exit is left out on iOS.
