Description

Support routines for the Sprite3D application that are neither UI nor library.

The application keeps three kinds of code apart. The units in ui only handle the user interface; the units in lib are a library with no knowledge of this application, usable in other projects; and this unit holds what is left: the application's own rules, such as where models are found, how grabs are named and saved, and how a loaded model is placed. It uses the library and the RTL, never the UI.

TSprite3DAppSettings holds the settings kept between sessions, in settings.json in the application's own per-user folder, SupportFolder.

Loading a model through LoadModelFile also registers Gorilla3D's loaders for glTF, FBX, OBJ, USD, Collada, STL and PLY files, as this unit uses them.

All routines are for the main thread.

function Wrap360(const ADegrees: Single): Single;

Shifts an angle in degrees by whole turns into the range 0 to 360.

Parameters
ADegrees
Any angle in degrees, negative or past a full turn.
Returns

The same direction as an angle from 0 up to, but not including, 360.

function DegreesText(const ADegrees: Single): String;

Formats an angle from Wrap360 as whole degrees for a readout.

Rounds to the nearest degree, so 359.6 shows as 0, never 360, and pads to three characters so readouts stay the same width.

Parameters
ADegrees
An angle from 0 up to 360.
Returns

The angle as text, such as ' 0' or ' 45'.

function DefaultModelDir: String;

The folder that holds the application's models folder, for this platform.

The library path on macOS, the home folder on Linux and '../../../' elsewhere; on Windows it is the current folder instead, returned as an empty string, if that has a models subfolder.

Returns

A folder path ending in a path delimiter, or empty for the current folder.

function DefaultGrabFolder: String;

The folder grabs are saved in without asking, or empty where the user should choose.

Android and iOS have no folder dialog, so there grabs go to a fixed Grabs folder the user can reach: under the app's public storage on Android, which shows over USB or in a file manager, and under its Documents folder on iOS, which shows in the Files app once the app enables file sharing in its Info.plist. Elsewhere this returns an empty string.

Returns

The fixed grab folder on Android and iOS; an empty string on other platforms.

function NextNumberedFileName(const AFolder, APrefix, AExtension: String; var ANumber: Integer): String;

The first free numbered file name in a folder, such as grab001.png.

Starts at ANumber and moves it past every name already taken, so an existing file is never chosen. Numbers have at least three digits. The file is not created.

Parameters
AFolder
The folder to look in.
APrefix
The start of the file name, such as 'grab'.
AExtension
The extension, with its dot, such as '.png'.
ANumber
The number to try first; on return, the number of the name returned.
Returns

The full path of the first name that does not exist yet.

function SaveGrab(const ABitmap: TBitmap; const AFolder: String; var ANumber: Integer): String;

Saves a grab as the next free grabNNN.png in a folder.

Creates the folder if needed, picks the name with NextNumberedFileName starting at ANumber, saves ABitmap there as PNG and moves ANumber on to the next number. Blocks while the file is written.

Parameters
ABitmap
The image to save; it is not freed.
AFolder
The folder to save in.
ANumber
The number to try first; on return, one past the number used. Unchanged if the save fails.
Returns

The full path of the file written.

Exceptions raised
Exception
If the folder cannot be created or the file cannot be written; the class depends on the cause.
function LoadModelFile(const AModel: TGorillaModel; const AFileName: String; out ABox: TBoundingBox): TArray<String>;

Replaces a model's contents with a model file and starts its last animation.

Clears AModel, loads AFileName into it, and, if the file has animations, plays the one whose name sorts last. Blocks while the file loads.

Parameters
AModel
The model to load into; its old contents are removed first.
AFileName
A glTF, FBX, OBJ, USD, Collada, STL or PLY file.
ABox
The model's bounding box straight after loading, before anything is added to it or it is moved; pass it to PlaceModel.
Returns

The names of the model's animations in sorted order; empty if it has none.

Exceptions raised
Exception
If the file cannot be read or loaded; AModel is then left cleared or part-loaded.
procedure PlaceModel(const AModel: TGorillaModel; const ABox: TBoundingBox);

Centres a loaded model on its bounding box and turns it right way up.

Moves AModel to the centre of ABox and turns it 180 degrees about X, which the application's models need to stand upright.

Parameters
AModel
The model to place.
ABox
The box LoadModelFile returned for it.
function IsModelFile(const AFileName: String): Boolean;

Whether a file is a model LoadModelFile can load, judged by its extension.

The extensions are those of the loaders this unit registers: .glb, .gltf, .fbx, .obj, .usdc, .dae, .stl and .ply, in any case. The file's contents are not checked.

Parameters
AFileName
A file name or path.
Returns

True if its extension is one of the model formats.

function AutoIconFileName(const AExtension: String): String;

The file an icon is saved to without asking, or empty where the user should choose.

Android and iOS have no save dialog, so there icons go to the next free iconNNN name, with AExtension, in DefaultGrabFolder. Elsewhere this returns an empty string, and the user picks the file.

Parameters
AExtension
The icon format's extension, with its dot, such as '.ico'.
Returns

The full path on Android and iOS; an empty string on other platforms.
