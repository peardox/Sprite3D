Description

Demo form for TSprite3DCamera: loads a model and drives the camera with dials.

The form has two tabs. The View tab holds a TGorillaViewport, created at run time, and a panel of three dials for Azimuth, inclination and Roll, plus four check boxes: one shows the model's own X, Y and Z axes through its centre of rotation, one a grid on its floor, one chooses how the model is fitted, and one switches between perspective and orthographic projection. The Debug tab holds a memo for log output.

The camera starts in the isometric view, and each readout always shows its dial's angle, from 0 to 359 degrees. Azimuth is sent to the camera reversed, 360 minus the readout, so the view turns the right way for the dial. View, Variable lets the dials set the angles; View, Isometric, the default for now, sets the readouts to inclination 35.264, azimuth 45 and roll 0, the true isometric view, and switches the dials off. A test slider along the bottom of the 3D view moves the camera out from the fitted distance, x1 to x20.

On show, the form loads the model whose file FormShow names; File, OpenModel then loads any other glTF, FBX, OBJ, USD, Collada, STL or PLY file. Each model replaces the last: it plays its last animation by name if it has any, is centred and turned 180 degrees about X, and the camera is fitted so it fills the view. The model is refitted when the viewport is resized, the projection changes or the "Fit any angle" box is toggled, but not when a dial turns. Checked, that box uses FitToBoundsMax, which frames the model for every angle at once, so the dials can never push it out of view. Unchecked, FitToBounds frames it exactly for the angles at the time of the fit, and turning a dial afterwards can push part of it past the edge until the next refit.
