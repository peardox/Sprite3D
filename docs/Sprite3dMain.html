Description

Demo form for TSprite3DCamera: loads a model and drives the camera with dials.

The form has two tabs. The 3D tab holds a TGorillaViewport, created at run time, and a panel of three dials for Azimuth, inclination and Roll, plus a check box that switches between perspective and orthographic projection. The Debug tab holds a memo for log output.

On show, the form loads models/TestModel.glb, plays its last animation by name, centres and turns it 180 degrees about X, and calls FitToBounds so it fills the view. The model is refitted whenever a dial turns, the viewport is resized, the projection changes or the "Fit any angle" box is toggled. Checked, that box uses FitToBoundsMax, which frames the model for every angle at once; unchecked, FitToBounds frames it exactly for the current angles.
