Declaration

type TForm1 = class(TForm)

Description

The main form: a Gorilla3D view of one model, with dials for the camera.

The viewport, light, model and TSprite3DCamera are created at run time, not at design time; the form owns none of them directly. All event handlers run on the main thread.

See also
TSprite3DCamera
A TGorillaCamera that orbits a centre point through a chain of three pivots.

Public chkFitAnyAngle: TCheckBox;

Chooses FitToBoundsMax over FitToBounds, so the model fits at every angle.

Checked, the model is framed once for every possible Azimuth, inclination and Roll and turning the dials only moves the camera round it. Unchecked, the model is framed exactly for the current angles and refitted after every dial change.

Methods

Public procedure FormCreate(Sender: TObject);

Sets up the viewport, light and camera, and picks the models folder.

The models folder is the library path on macOS, the home folder on Linux and '../../../' elsewhere; on Windows it is the current folder instead if that has a models subfolder. The handler creates a TGorillaViewport owned by ViewportLayout, a point light, and a TSprite3DCamera with a 45-degree FOV, which becomes the viewport's camera. The viewport runs at a fixed 60 frames per second without VSync.

Public procedure AzimuthDialChange(Sender: TObject);

Copies AzimuthDial to the camera's Azimuth.

The dial value is negated and shifted into 0 to 360, shown in AzimuthText, and written to the camera; the model is then refitted for the new view.

Parameters
Sender
AzimuthDial.
Public procedure AngleDialChange(Sender: TObject);

Copies AngleDial to the camera's PolarAngle.

The dial value is negated and shifted into 0 to 360, shown in AngleText, and written to the camera; the model is then refitted. Values past 90 take the camera over the pole.

Parameters
Sender
AngleDial.
Public procedure RollDialChange(Sender: TObject);

Copies RollDial to the camera's Roll.

The dial value is shifted into 0 to 360, without negating, shown in RollText, and written to the camera; the model is then refitted for the new view.

Public procedure chkOrthoToggleChange(Sender: TObject);

Switches the projection to match chkOrthoToggle and refits the model.

Sets ProjectionMode to cpOrthographic or cpPerspective, puts the mode's name in the form caption, and calls FitToBounds, since the two modes size the view differently.
