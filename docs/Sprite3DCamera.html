Description

Orbit camera for Gorilla3D, driven by a chain of three single-axis pivots.

TSprite3DCamera is a TGorillaCamera that hangs at the end of a chain of three TDummy pivots. Each pivot turns about one axis only, so Azimuth, PolarAngle and Roll never combine as Euler angles on one object, and the camera can pass over the poles without gimbal lock. The camera sits Distance units back from the orbit centre and always looks at it. 

<your parent>                      e.g. TGorillaViewport, or any TControl3D
`-- AzimuthPivot (TDummy)         rotates about Y  ->  Azimuth
    `-- PolarPivot (TDummy)       rotates about X  ->  PolarAngle
        `-- RollPivot (TDummy)    rotates about Z  ->  Roll
            `-- TSprite3DCamera    at (0, 0, -Distance), looking along +Z

Angles are in degrees. The orientation is the quaternion Qy(Azimuth) * Qx(-PolarAngle) * Qz(Roll) in the rig parent's space, and TQuat does the arithmetic. FMX's up direction is -Y.

LookAt turns the camera where it stands to face a point. FitToBounds makes a box as large as possible in the viewport without overflowing it, in perspective or orthographic mode, for the current angles. FitToBoundsMax does the same for every possible Azimuth, PolarAngle and Roll, so the angles can then change freely. The header comment after the unit line explains the maths behind them. 

Cam := TSprite3DCamera.Create(Self);
Cam.Rig.Parent := GorillaViewport1;   // parent the whole chain, not Cam itself
GorillaViewport1.Camera := Cam;
GorillaViewport1.UsingDesignCamera := False;
Cam.FitToBounds(GorillaModel1);

TLookAtMode = (...);

How LookAt treats Roll when it turns the camera.

See also
TSprite3DCamera.LookAt
Turns the camera, from where it stands, to face APoint.
Values
  • lmMinimalTwist: The default. A pure shortest-arc turn: the camera keeps as much of its current up direction as it can. Repeated LookAt calls can build up some roll.
  • lmKeepRoll: The same view direction, but Roll keeps its current value, so the horizon stays as it was. Still safe at the poles, where Azimuth is held.
