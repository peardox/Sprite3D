Description

Draws a model's X, Y and Z axes through its centre of rotation.

ShowModelAxes adds a TModelAxes to a TGorillaModel. In each frame's main pass it draws three lines with the context's DrawLine helper: red along X, green along Y and blue along Z. They cross at the model's centre of rotation, which is FMX's RotationCenter in the model's own coordinates and is the model's origin unless that has been changed. Each line runs from one face of the model's bounding box to the opposite face, so unless the centre of rotation lies outside that box, the lines stay inside the box that FitToBounds frames.

The axes are a child of the model and are drawn with their own AbsoluteMatrix, so they move, turn and scale with the model and show its own axes rather than the scene's. FMX's Y axis points down the screen, so with no rotation the green line's positive end is at the bottom. By default the lines are 1 pixel wide and drawn with depth testing off, so the model never hides them.

This follows Gorilla v1.5's Line Rendering guide: a TDummy descendant that overrides Render, sets and restores the context matrix, draws only in the main pass, and wraps a wider line width in BeginLineRendering and EndLineRendering. Widths above 1 pixel work on desktop OpenGL only; Vulkan, Metal and OpenGL ES always draw 1 pixel. 

TGorillaModel
`-- TModelAxes      one per model, found by FindModelAxes;
                    draws the three lines in its Render

ShowModelAxes(GorillaModel1);    // after the model is loaded
HideModelAxes(GorillaModel1);

function ShowModelAxes(const AModel: TGorillaModel; const ALineWidth: Single = 1; const AOnTop: Boolean = True): TModelAxes;

Draws AModel's X, Y and Z axes through its centre of rotation.

Any axes already on AModel are removed first, so calling it again, for example after loading a different model, redraws them for the new bounds. The lines cross at AModel.RotationCenter and each runs across AModel's current bounding box, from GetAnimatedBoundingBox, widened if need be to reach the centre of rotation. X is red, Y green and Z blue.

The axes are added as a child of AModel, so they follow its position, rotation and scale, and are freed with it. They are sized for the box at the time of the call. Call from the main thread only.

Parameters
AModel
The model to draw axes on. Nothing happens if it is nil.
ALineWidth
Line width in screen pixels. Values above 1 work on desktop OpenGL only.
AOnTop
True to draw the lines over everything, so the model cannot hide them; False to let the model hide the parts inside it.
Returns

The new axes, owned by AModel; or nil, with nothing added, if AModel is nil or its bounding box is empty.
