Description

Draws a far-reaching grid on a model's floor with a GLSL shader.

ShowModelGrid adds a TModelGrid to a TGorillaModel. It shows a grid of lines across one of the model's axes, Y by default, so the grid lies in X and Z. The lines are GridSize apart in the model's own units, 1.0 by default, in dark grey, with one through the model's centre of rotation, and the grid reaches GridCells cells each side of it, 1000 by default. Distant lines fade out as their cells shrink to a few pixels on screen, so the grid dissolves into the distance rather than stopping at an edge. GridLevel is where it crosses its axis; with GridOnFloor, the default, that is the model's floor, the bounding-box face across the grid's axis that is lower in the scene. That suits a model standing on its lowest bound, as the test animation does, but not every model; set GridLevel to override it.

The grid is a single TGorillaPlane. The lines are worked out per pixel by GLSL code in its TGorillaDefaultMaterialSource, through its documented SurfaceShader hook, which Gorilla converts for Vulkan and Metal. So the grid costs two triangles however far it reaches, the lines are anti-aliased and about a pixel wide at any distance, and nothing is recalculated per frame. Changing a grid property rewrites the shader once, with the new values written into it as constants.

The plane is not a child of the model, so it never counts in the model's bounding box, and FitToBounds is unaffected. It sits in a frame beside the model that copies the model's position, rotation, scale and centre of rotation whenever they change, so the grid is in the model's units and moves with it. 

<model's parent>
|-- TGorillaModel
|   `-- TModelGrid       one per model, found by FindModelGrid;
|                        keeps the frame on the model's transform
`-- grid frame           TDummy copying the model's transform, owned by the TModelGrid
    `-- TGorillaPlane    turned onto GridAxis at GridLevel; grid drawn by its shader

Grid := ShowModelGrid(GorillaModel1);   // after the model is loaded and placed
if Grid <> nil then
  Grid.GridSize := 0.5;
HideModelGrid(GorillaModel1);

function ShowModelGrid(const AModel: TGorillaModel): TModelGrid;

Shows a shader-drawn grid on AModel's floor.

Any grid already on AModel is removed first, so calling it again, for example after loading a different model, rebuilds it for the new bounds. The grid uses AModel's current bounding box, from GetAnimatedBoundingBox, and AModel.RotationCenter. Call it once the model is placed and turned, since the floor depends on the turn. The grid is added as a child of AModel and is freed with it. Call from the main thread only.

Parameters
AModel
The model to show a grid for. Nothing happens if it is nil.
Returns

The new grid, owned by AModel; or nil, with nothing added, if AModel is nil or its bounding box is empty.

The axis a TModelGrid is drawn across.

The grid lies in the plane of the other two axes.

Values
  • gaX: Across X: the grid lies in Y and Z.
