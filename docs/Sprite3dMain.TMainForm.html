Sprite3dMain

Declaration

type TMainForm = class(TForm)

Description

The main form: a Gorilla3D view of one model, with dials for the camera.

The viewport, light, model and TSprite3DCamera are created at run time, not at design time; the form owns none of them directly. All event handlers run on the main thread.

See also
TSprite3DCamera
A TGorillaCamera that orbits a centre point through a chain of three pivots.

Public chkFitAnyAngle: TCheckBox;

Chooses FitToBoundsMax over FitToBounds, so the model fits at every angle.

Checked, the model is framed for every possible Azimuth, inclination and Roll, so turning the dials only moves the camera round it and the model always stays in view. Unchecked, the model is framed exactly for the angles at the time of the fit; turning a dial afterwards can push part of it past the edge until the next refit, which happens on a resize, a projection change or toggling this box.

Public chkShowAxes: TCheckBox;

Shows or hides the model's X, Y and Z axes; checked at start-up.

Checked, every model is loaded with ShowModelAxes from Sprite3DAxes, which draws red, green and blue lines through its centre of rotation; unchecked, they are removed.

Public chkShowGrid: TCheckBox;

Shows or hides the floor grid; checked at start-up.

Checked, every model is loaded with ShowModelGrid from Sprite3DGrid, which draws a shader grid of grey lines 1.0 apart on the model's floor; unchecked, it is removed.

Public OpenDialog1: TOpenDialog;

Its filter, set in the form designer, offers only the formats the unit has loaders for: .glb, .gltf, .fbx, .obj, .usdc, .dae, .stl and .ply, all together first and then one at a time.

Public procedure FormCreate(Sender: TObject);

Sets up the viewport, light and camera, and picks the models folder.

The models folder is the library path on macOS, the home folder on Linux and '../../../' elsewhere; on Windows it is the current folder instead if that has a models subfolder. The handler creates a TGorillaViewport owned by ViewportLayout, a point light, and a TSprite3DCamera with a 45-degree FOV, which becomes the viewport's camera. The viewport runs at a fixed 60 frames per second without VSync.

The dials start at 0, then the isometric view is chosen, as View, Isometric does: the dials are turned to its angles and switched off, and the readouts set to match, so dial, readout and camera agree from the start.

Parameters
Sender
The form.
Public procedure FormShow(Sender: TObject);

Loads the first model from the models folder and fits the camera to it.

The file is named in this handler; change it there to start with a different model, or use File, OpenModel once the form is up. Shows a message and loads nothing if the file is missing or cannot be read.

Public procedure AzimuthDialChange(Sender: TObject);

Copies AzimuthDial to the camera's Azimuth.

The dial value is negated, wrapped into 0 to 360 and shown in AzimuthText. The camera gets the angle reversed, 360 minus the readout, so the view turns the right way for the dial. The model is not refitted; see chkFitAnyAngle.

Parameters
Sender
AzimuthDial.
Public procedure AngleDialChange(Sender: TObject);

Copies AngleDial to the camera's PolarAngle.

The dial value is negated and wrapped into 0 to 360, shown in AngleText and written to the camera. Values past 90 take the camera over the pole. The model is not refitted; see chkFitAnyAngle.

Parameters

Public procedure RollDialChange(Sender: TObject);

Copies RollDial to the camera's Roll.

The dial value is wrapped into 0 to 360, without negating, shown in RollText and written to the camera. The model is not refitted; see chkFitAnyAngle.

Public procedure OpenModelMenuItemClick(Sender: TObject);

Lets the user pick a model file and loads it in place of the current one.

Shows OpenDialog1 and passes the chosen file to SwitchModel, which clears the old model and loads the new one with the current camera angles and fit mode. Nothing changes if the dialog is cancelled. A file that fails to load is reported by SwitchModel, and the view is then left empty until another model loads.

Public procedure ViewIsometricItemClick(Sender: TObject);

Sets the isometric view and fixes it.

Sets the inclination to 35.264, the true isometric elevation, the azimuth to 45 and the roll to 0, as shown on the readouts, turns the dials to match and switches them off, then refits the model for the new view. As with the dial, the azimuth reaches the camera reversed.

Parameters
Sender
ViewIsometricItem.
Public procedure DistanceTrackChange(Sender: TObject);

Moves the camera out by the slider's factor; test only.

In perspective mode the camera's Distance becomes the fitted distance times the factor; in orthographic mode, where distance does not change the size, OrthoHeight is scaled instead. The factor is kept when the model is refitted.
